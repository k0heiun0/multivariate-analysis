第2回 データ分割と汎化性能

作ったモデルは本当に使えるのか？

場面：「テストでは90点だったのに」

試験前、過去問を完璧に暗記した学生がいます。過去問は満点。本番はどうでしょうか。

同じ曲線です。 覚えた問題に合わせすぎると、本番で使えなくなります。

今回の問い

前回、カリフォルニア住宅価格のモデルを作り、訓練データで R^2 \approx 0.6 を得た。

しかし……

  • このモデルは、新しい住宅データでも同じ精度が出るのか？
  • 訓練データへの当てはまりが良ければ、それで十分なのか？

今回のキーワードは「汎化性能」。手元のデータではなく、未知のデータでの実力を測る。

具体化：手元のデータに合わせすぎると

緑が真の関係、赤がデータの点を追いかけすぎたモデル。点には合うが、真の関係からはむしろ遠い。

データの四角形：行を分けて汎化を測る

汎化性能＝見ていない行での成績。「行を隠す」という操作が今回の主役。列は切らない。

多項式の次数を上げるとどうなるか

次数1は単純すぎ（未学習）、次数15は曲がりくねって過学習。テスト誤差は次数15で跳ね上がる。

素朴な限界：訓練誤差だけ見ると

「訓練誤差が小さいモデルが良いモデル」と思うと、必ず一番複雑なモデルを選んでしまう。

訓練誤差は単調に下がる。だがテスト誤差はU字。最小になる次数3こそが、本当に良いモデル。

位置づけ：今回の地図

前回はモデルを作る段階。今回は正しく評価する段階。

目的 モデルを当てはめる 汎化性能を測る
見る数字 訓練の R^2 テストの R^2・誤差

評価を学ばないと、過学習を「良いモデル」と誤認する。

行列で見る：訓練とテストは行の分割

分割とは 行の集合を2つに分ける 操作。

定義①：汎化誤差

E_{\text{gen}} = \mathbb{E}_{(x,y)\sim P}\left[(y - \hat{f}(x))^2\right]

  • P：母集団の分布（未知）
  • \hat{f}：手元のデータで学習したモデル

「手元の当てはまり」ではなく「未知データでの期待誤差」が真の目標。

定義②：訓練誤差は楽観的すぎる

E_{\text{train}} = \frac{1}{n}\sum_{i=1}^{n}\bigl(y_i - \hat{f}(x_i)\bigr)^2

  • \hat{f} は x_i, y_i に合うように作られた
  • だから汎化誤差より小さく出る

訓練誤差を信じると過学習を見逃す。別のデータで測る。

定義③：ホールドアウト法（Train/Test 分割）

テストデータは「未知データの代役」。だから学習に混ぜたら意味がなくなる。

定義④：Train / Valid / Test の3分割

モデルを選ぶ作業でテストを使うと、テストが「未知」でなくなる。だから3つに分ける。

検証は何度比べてもよい。だがテストは本番の試験。何度も見てはいけない。

定義⑤：期待値・分散・独立

\mathbb{E}[aX+bY+c]=a\,\mathbb{E}[X]+b\,\mathbb{E}[Y]+c

X,\,Y\text{ が独立}\;\Longrightarrow\;\mathbb{E}[XY]=\mathbb{E}[X]\,\mathbb{E}[Y]

  • 期待値：無限回の平均。和と定数倍を通す（線形）
  • 分散：\operatorname{Var}(X)=\mathbb{E}\bigl[(X-\mathbb{E}[X])^2\bigr]
  • 要点：\mathbb{E}\bigl[(X-\mathbb{E}[X])\,c\bigr]=0（平均まわりのずれは消える）

導出①：バイアス・バリアンス分解（狙い）

\mathbb{E}\bigl[(y - \hat{f}(x))^2\bigr]

読み方：この一つの量を、意味の違う三つの部分に分けたい。

y = f(x) + \varepsilon、ノイズは平均0・分散 \sigma^2（定義⑤）とする。 バイアス・バリアンス・ノイズに分けていく。

導出②：項を足して引く

予測の平均 \bar{f} = \mathbb{E}[\hat{f}] を引いて足す。

\mathbb{E}\bigl[(y-\hat f)^2\bigr] = \mathbb{E}[(y-\bar f)^2] + \mathbb{E}[(\bar f-\hat f)^2]

読み方：誤差は「ノイズと真とのズレ」に「予測のばらつき」を足したもの。

交差項は定義⑤の要点どおり 0（\hat f の平均が \bar f、y は \hat f と独立）。 平均まわりに分けるのがコツ。

導出③：分解の完成

\mathbb{E}\bigl[(y-\hat f(x))^2\bigr] = (f-\bar f)^2 + \mathbb{E}[(\bar f-\hat f)^2] + \sigma^2

読み方：誤差は、バイアスの二乗とバリアンスとノイズの三つに分かれる。

  • \text{Bias}^2：系統的なズレ（単純すぎると大）
  • \text{Variance}：予測の暴れ（複雑すぎると大）
  • \sigma^2：どんなモデルでも消せない下限

導出④：トレードオフを図で見る

複雑さを上げると Bias は下がるが Variance は上がる。和が最小の点が最適。

未学習は Bias 過多、過学習は Variance 過多。ちょうど良い複雑さを選ぶのが目標。

手順①：train_test_split の使い方

scikit-learn なら分割は1行。現実データで訓練・テストの R^2 を比べてみる。

デモ②：訓練とテストのギャップ

訓練誤差とテスト誤差の差そのものを見ると、過学習の進み具合が分かる。

低次数ではギャップは小さく、高次数になるほど全体として開いていく。ギャップの拡大こそ過学習の指標。

デモ③：学習曲線（データ量 × 誤差）

過学習モデルもデータが増えるとギャップが縮む。データ量は薬になる。

デモ④：分割の乱数を変えてみる

同じデータ・同じモデルでも、分割しだいで R^2 は 0.57〜0.62 の幅で動く。20回の平均は 約0.60。

解釈①：U字曲線の読み方

テスト誤差のU字には、左右で意味がある。

  • 左側（単純すぎ）：訓練もテストも誤差が大きい → 未学習（high bias）
  • 右側（複雑すぎ）：訓練誤差は小、テスト誤差は大 → 過学習（high variance）
  • 底：両者のバランスが取れた、最も汎化する複雑さ

訓練誤差とテスト誤差を並べて見れば、今どちら側にいるかが判断できる。

解釈②：ギャップと学習曲線の読み方

  • ギャップが大 → Variance 過多。データを増やすか単純化
  • 両方高くギャップ小 → Bias 過多。モデルを複雑に
  • 曲線がまだ収束していない → データを増やす価値あり
  • 曲線が早々に平ら → モデルを変える

数字1個ではなく曲線の形で診断する。

解釈③：σ² という越えられない壁

両方の誤差が近づく先には、ノイズの下限 \sigma^2 がある。

誤差ゼロは目標ではない。 \sigma^2 に届くまで Bias と Variance を削る。

次数3が最もよく汎化すると読めた——ただ、これらの評価には落とし穴があるかもしれない。

落とし穴①：テストセットを何度も見る

見るほど数字は良くなる。だが実力は上がっていない。 選択は検証データで行う。

落とし穴②：データリーク

テストの情報が訓練に漏れ込むと、評価は壊れる。気づきにくいのが厄介。

前処理は訓練だけで fit、テストには transform だけ（第3回）。

落とし穴③：分割の乱数依存

デモ④で見たとおり、1回の分割の数字は揺れる。

  • データが少ないほど、テストセットの「当たり外れ」が大きい
  • たまたま簡単なテストを引けば R^2 は高く、難しいと低く出る
  • 1回の分割だけで「このモデルは良い／悪い」と断定するのは危険

対策は「分割を変えて何度も評価し、平均する」こと。これが次回の伏線になる。

発展①：クロスバリデーションへの橋渡し

「分割を何度も変えて平均」を体系化したのがクロスバリデーション（CV）。

第4回で詳しく学ぶ。

発展②：データ量と汎化の関係

学習曲線が教えてくれた、実務で効く原則。

  • データを増やすのは Variance を直接下げる確実な方法
  • ただし Bias は減らない。単純すぎれば頭打ち
  • どちらが必要かは学習曲線の傾きで判断する

「とりあえず複雑なモデル」より「まずデータと評価設計」。

まとめ

Key Takeaways:

  1. 訓練誤差 ≠ 汎化誤差 訓練誤差は楽観的。未知データでの誤差を、テストデータで近似する

  2. 誤差は Bias² + Variance + σ² に分かれる 単純すぎれば Bias、複雑すぎれば Variance。和を最小にする複雑さを選ぶ

  3. テストは最後の一度だけ・リーク厳禁・1回の分割を過信しない 評価の設計が、モデルそのものと同じくらい大切
