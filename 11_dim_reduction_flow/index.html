第11回 SVD と低ランク近似

64次元を2次元にするとき、何を失っているのか——近似誤差を最小にする問題として解く

場面：「64列、全部いりますか？」

手書き数字は64列あります。全部が必要でしょうか。減らしたら何が失われるでしょうか。

16列でもほぼ読めます。 どこまで削れるか、その基準を作るのが今日の話です。

今回の問い

64次元の手書き数字を2次元に落として眺めると、数字ごとのまとまりが見える。

  • だが 2次元にした時点で、62次元ぶんの情報は捨てている
  • 何をどれだけ捨てたのか。その捨て方は「これが最善」と言えるのか
  • 「よい圧縮」を式で定義できるか？

今回は、次元縮小を 近似誤差を最小にする問題 として立て直す。答えは特異値分解が与える。

データの四角形：列を 64→k に圧縮する

列を減らしても、1枚の画像＝1行は変わらない。 k をいくつにするか、何を保つのかが今回の主題。

EDA：64次元をそのまま見られるか

  • 2ピクセルの散布図では10クラスが団子になる
  • 64次元すべてが等しく効くわけではない

定義①：低ランク近似とは何か

\mathbf{X}\in\mathbb{R}^{n\times p} を、もっと単純な行列 \mathbf{A} で置き換えたい。

定義②：何を最小にするか

「近い」を成分ごとの二乗和で測る。フロベニウスノルムという。

\lVert \mathbf{X}-\mathbf{A} \rVert_F^2 = \sum_{i=1}^{n}\sum_{j=1}^{p}\bigl(x_{ij}-a_{ij}\bigr)^2

読み方：もとの行列と近似行列の差を、成分ごとに二乗して全部足す。

定義③：ランク制約つき最小化問題

今回の問いはこの一行に書ける。

\min_{\mathbf{A}} \; \lVert \mathbf{X}-\mathbf{A} \rVert_F^2 \quad \text{subject to} \quad \operatorname{rank}(\mathbf{A}) \le k

読み方：ランクが k 以下という制約のもとで、その差を最小にする \mathbf{A} を探す。

目的関数は近似誤差、制約はランク k 以下。 制約が無ければ誤差はゼロ。制約があるから圧縮になる。

デモ：k を変えて誤差を見る

U, S, Vt = np.linalg.svd(X_std, full_matrices=False)
ks = [1, 2, 4, 8, 16, 32, 64]
err = [np.sum(S[k:] ** 2) for k in ks]     # 打ち切った特異値の二乗和

k を増やすほど誤差は単調に減る。どこまで減らせば十分かを次に考える。

解釈：誤差の落ち方が寄与率

\frac{\sum_{j\le k}\sigma_j^2}{\sum_{j}\sigma_j^2} \;=\; 1 - \frac{\lVert\mathbf{X}-\mathbf{X}_k\rVert_F^2}{\lVert\mathbf{X}\rVert_F^2}

読み方：上位 k 個の特異値の二乗和を、全特異値の二乗和で割る。累積寄与率は誤差の裏返しである。

［再訪］標準化は答えを変える

v = X.var(axis=0)
print(f"標準化前の分散の範囲: {v.min():.2f} 〜 {v.max():.2f}")
print(f"分散ゼロのピクセル数: {(v == 0).sum()} 個")
標準化前の分散の範囲: 0.00 〜 42.72
分散ゼロのピクセル数: 3 個

導出①：特異値分解を思い出す

第10回の特異値分解を今回の主役にする。

\mathbf{X} = \mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^\top = \sum_{j=1}^{r}\sigma_j\,\mathbf{u}_j\mathbf{v}_j^\top

読み方：どんな行列も、三つの行列の積に分けられる。真ん中が特異値。

\mathbf{u}_j\mathbf{v}_j^\top はランク1の行列。\mathbf{X} を r 枚の重ね合わせと見る。 特異値 \sigma_j は、その1枚の重みである。

導出②：Eckart–Young の主張

ランク k 以下の行列のうち \lVert\mathbf{X}-\mathbf{A}\rVert_F を最小にするのは、SVDの上位 k 項だけを残したもの。

\mathbf{X}_k=\sum_{j=1}^{k}\sigma_j\mathbf{u}_j\mathbf{v}_j^\top \qquad \lVert\mathbf{X}-\mathbf{X}_k\rVert_F^2=\sum_{j>k}\sigma_j^2

  • 「重みの大きい順に k 枚取る」という素朴な方法が、本当に最適だと言っている
  • 誤差は 捨てた特異値の二乗和 そのもの

導出③：なぜ上位k項が最適なのか

  1. \mathbf{U} と \mathbf{V} は直交行列。直交変換はフロベニウスノルムを変えない
  2. だから誤差は特異値の二乗和に分解できる

\lVert\mathbf{X}\rVert_F^2=\sum_{j=1}^{r}\sigma_j^2=\sum_{j\le k}\sigma_j^2+\sum_{j>k}\sigma_j^2

  1. 残す側を最大にするには、大きい順に k 個取ればよい

図で見る：捨てた特異値が誤差そのもの

k を動かすとは、この棒グラフのどこで線を引くかを決めること。

導出④：PCA との同値性

中心化した \mathbf{X} の共分散行列 \mathbf{S}=\frac{1}{n-1}\mathbf{X}^\top\mathbf{X} に \mathbf{X}=\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^\top を入れると

\mathbf{X}^\top\mathbf{X} = \mathbf{V}\boldsymbol{\Sigma}^2\mathbf{V}^\top

第10回と今回は同じ計算をしていた。分散の最大化と近似誤差の最小化は裏表。

デモ：上位k項で数字を再構成する

mean = X.mean(axis=0)
U0, S0, V0t = np.linalg.svd(X - mean, full_matrices=False)
recon = lambda k: (U0[:, :k] * S0[:k]) @ V0t[:k] + mean   # 上位k項だけの近似

k=8 で数字は読める。64次元のうち8方向で、見た目のほとんどが再現できている。

行列で見る：線形も非線形も同じ形

線形（PCA）は \mathbf{V} の先頭 k 列を掛けるだけ。非線形（t-SNE / UMAP）も n\times p \to n\times k という変換の形は同じ。違うのは何を目的関数に選ぶか。

別の問いの立て方：近さの確率を保つ

誤差を測るのではなく、分布を合わせる。目的関数が変われば、出てくる図も変わる。

定義：t-SNE の目的関数

高次元での近さ p_{ij}（ガウス）と、低次元での近さ q_{ij}（t分布）を作り、低次元の配置 \{y_i\} を次で決める。

\min_{\{y_i\}} \; \mathrm{KL}(P\,\|\,Q)=\sum_{i\neq j} p_{ij}\log\frac{p_{ij}}{q_{ij}}

  • p_{ij}\propto\exp(-\lVert x_i-x_j\rVert^2/2\sigma_i^2)、q_{ij}\propto(1+\lVert y_i-y_j\rVert^2)^{-1}
  • 近似誤差ではなく、分布のズレを最小にしている

定義：perplexity が決めているもの

perplexity（近傍の有効数）と crowding problem

perplexity は各点の「近傍とみなす有効な点数」を決め、\sigma_i を介して近傍範囲を調整する。 小さいと局所構造、大きいとより広い構造を重視。通常 5〜50 で試す。 低次元に t分布（裾が重い）を使うのは、高次元の体積を低次元に詰め込む際に点が中心へ 潰れる crowding problem を緩和するため。

  • perplexity は \sigma_i を通じて p_{ij} の裾の広さを決める
  • つまり「どこまでを近いとみなすか」というパラメータ
  • 目的関数そのものが変わるので、値を変えれば出てくる図も変わる

解き方：閉形式と勾配降下

目的関数の形が解き方まで決めてしまう。

低ランク近似 t-SNE
性質 目的関数は凸（制約は非凸） 非凸
解き方 閉形式 勾配降下
答え 一意 初期値しだい

デモ：PCA と t-SNE を並べる

Z_pca_sub = PCA(n_components=2, random_state=42).fit_transform(X_sub)
Z_tsne = TSNE(n_components=2, perplexity=30, random_state=42,
              init='pca').fit_transform(X_sub)   # 1000点に絞って実行

同じデータ・同じ2次元でも、目的関数が違うだけでこれだけ違う絵になる。

帰結①：距離を保存しないのはなぜか

t-SNE の図で クラスター間の距離は意味を持たない。これは欠陥ではなく目的関数の帰結。

  • 目的は p_{ij} と q_{ij} を合わせること。距離を合わせるとは一言も言っていない
  • 低次元の t分布は裾が重く、遠距離を強く圧縮する
  • 読んでよいのは「同じ色が固まっているか」だけ。隙間の広さは読まない

帰結②：大域構造が壊れる理由

p_{ij} は近傍に重みを集中させる。遠い組は p_{ij}\approx 0 なので

p_{ij}\log\frac{p_{ij}}{q_{ij}} \approx 0

読み方：もともと遠い点は p_{ij} がほぼ0。どこへ置いても損失が増えない。

遠い点の関係は目的関数にほとんど寄与しません。最小化は近傍に使われ、 大域的な配置は放置されます。クラスターの大きさや密度も同じ理由で反映されません。

帰結③：再現性がないのはなぜか

KL の最小化は非凸。初期値が違えば別の局所解に落ちる。SVD が毎回同じ答えを返すのと対照的で、これも目的関数の性質から来ている。

落とし穴：perplexity で見え方が変わる

perplexity を変えると目的関数そのものが変わる。だから粒度も変わる。小さいと細かく割れ、大きいと大きな塊にまとまる。1枚の図だけで構造を断定しない。

帰結④：可視化座標を予測に使えない理由

knn_bad = KNeighborsClassifier(n_neighbors=5)
acc_tsne = cross_val_score(knn_bad, Z_tsne, y_sub, cv=5).mean()
X_pca30 = PCA(n_components=30, random_state=42).fit_transform(X_sub)
acc_pca = cross_val_score(knn_bad, X_pca30, y_sub, cv=5).mean()
print(f"t-SNE 2次元を特徴量にしたKNN精度: {acc_tsne:.3f}（不適切）")
print(f"PCA 30次元を特徴量にしたKNN精度  : {acc_pca:.3f}")
t-SNE 2次元を特徴量にしたKNN精度: 0.957（不適切）
PCA 30次元を特徴量にしたKNN精度  : 0.965

t-SNE の目的関数は 座標そのもの について定義されている。だから新しい点を写す写像が存在せず、transform も逆変換も作れない。精度が高く見えても前処理には使えない。

［再訪］計算コストの出どころ

t0 = time.time(); PCA(n_components=2).fit_transform(X_sub)
t_pca = time.time() - t0
t0 = time.time(); TSNE(n_components=2, perplexity=30,

PCA 0.0023秒 / t-SNE 1.55秒 = 680倍

［再訪］k を削ると下流はどうなるか

k を削ると近似誤差が増える。それが下流の分類精度に伝わる。30次元までは誤差の増加が小さく精度は保たれ、そこを割ると急落する。

発展：UMAP もまた別の目的関数

  • 目的関数を変えれば、得意なことも変わる——UMAP は大域構造をいくらか保つ
  • ただし非凸を勾配降下で解く点は同じ。乱数依存と「可視化専用」は共通
  • 手法を覚えるのではなく、何を最小化しているかを見る

［再訪］3用途を書き直す

用途 何を最小化するか 評価基準
可視化 局所の近さ（t-SNE / UMAP） 見た目の分離
前処理 近似誤差（PCA / SVD） 下流の精度
解釈 近似誤差（PCA / 因子分析） 寄与率・負荷量

いまは同じ表を目的関数の言葉で書ける——「どの手法がよいか」ではなく「何を最小化したいか」から選ぶ。

実務：使いどころと限界

手法 向いている場面 限界・注意
PCA 前処理・解釈・高速可視化 線形のみ。曲がった構造は潰れる
t-SNE 局所構造の可視化 重い・乱数依存・距離は無意味
UMAP 大規模の可視化 乱数依存。距離解釈は同様に注意

迷ったらまず PCA。寄与率で削れる量を測る。 次元縮小は圧縮であって、情報を増やすものではない。

まとめ：3手法を目的関数で並べる

手法 目的関数 解き方 答え
PCA / SVD \lVert\mathbf{X}-\mathbf{A}\rVert_F^2 の最小化 閉形式（SVD） 一意
t-SNE \mathrm{KL}(P\|Q) の最小化 勾配降下 初期値依存
UMAP 近傍グラフの交差エントロピー 勾配降下 初期値依存

この1枚が今回の全部。

まとめ（3点）

  1. 圧縮は最小化問題として書ける —— \min\lVert\mathbf{X}-\mathbf{A}\rVert_F^2 subject to \operatorname{rank}(\mathbf{A})\le k
  2. その答えは SVD が与える —— Eckart–Young。誤差は捨てた特異値の二乗和。PCA と同じ計算だった
  3. 目的関数が変われば結果の性質も変わる —— 距離の非保存も再現性の欠如も、t-SNE の目的関数から出てくる帰結

手法を覚えるのではなく、何を最小化しているかを見る。これが多変量解析を貫く見方。
