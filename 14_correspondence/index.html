第14回 コレスポンデンス分析

カテゴリカルデータの関係をどう可視化するか——年齢層×好みのジャンルで読み解く

場面：「関係はある。で、どう関係する？」

検定が返すのは「ある／ない」だけ。 中身を地図にするのが今日の手法です。

今回の問い

  • 2つのカテゴリカル変数のクロス集計を、どう分析するか？
  • χ²（カイ二乗）検定で「関係あり」はわかる。でも 「どう」関係するか は？
  • 「10〜20代はアクション、70代以上はニュース」——こうしたパターンを見たい

→ 関係の パターンを可視化 するツール、コレスポンデンス分析 を学ぶ。

素朴な方法①：χ²検定で「関係の有無」を見る

chi2, p, dof, expected = chi2_contingency(ct)
print(f"χ² = {chi2:.2f}   p = {p:.2e}   自由度 = {dof}")
χ² = 147.67   p = 2.68e-27   自由度 = 9

独立なら起こりえない値です。 ですが分かるのはそこまで。

素朴な限界：検定は「どう関係するか」を語らない

χ²検定でわかること・わからないこと：

  • ✓ 独立性の 有無
  • ✗ どの年代がどれを好むかという パターン
  • ✗ カテゴリ間の 位置関係

位置づけ：分割表の解析という新しい土俵

  • 第10回：PCA——連続変数の分散を固有値分解で低次元に圧縮した
  • 第12回：クラスタリング——距離に基づき個体をグループ化した
  • 第14回（今回）：カテゴリカル変数の分割表を、低次元の図に圧縮する

PCA の考え方を分割表のχ²構造に当てたもの。行と列を同じ平面に置きます。

定義①：周辺度数と期待度数

E_{ij} = \frac{r_i \, c_j}{N}

\chi^2 = \sum_{i,j} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}

CAは、この 残差の構造 を低次元で表す手法である。

定義②：行プロファイルとχ²距離

d_\chi^2(i, i') = \sum_j \frac{1}{c_j/N}\left(\frac{O_{ij}}{r_i} - \frac{O_{i'j}}{r_{i'}}\right)^2

  • 各項を 列マス c_j/N で割るのがポイント
  • まれな（列マスが小さい）ジャンルの差ほど 重く 効く
  • χ²距離が近い行＝好みの構成比が似ている年代

定義③：慣性（イナーシャ）とは

CAでの「分散」にあたる量を慣性（inertia）と呼ぶ。

\text{総慣性} = \frac{\chi^2}{N} = \sum_{i,j} \frac{(p_{ij} - r_i c_j / N^2)^2}{r_i c_j / N^2}

読み方：総慣性は、カイ二乗値を全体の度数で割ったもの。ズレの総量を表す。

total_inertia = chi2 / ct.values.sum()
print(f"χ² = {chi2:.2f}   N = {ct.values.sum()}   総慣性 = χ²/N = {total_inertia:.4f}")
χ² = 147.67   N = 395   総慣性 = χ²/N = 0.3738

総慣性は「行プロファイルの散らばり」。CAはこれを少数の軸に分解する。

行列で見る：CA も四角形の分解

第10回の PCA は \mathbf{X} を、今回の CA は 残差行列 Z を分解する。対象が変わっただけで、操作は同じ。

定義④：標準化残差行列とSVD

計算の核は標準化残差行列への特異値分解。

Z_{ij} = \frac{O_{ij} - E_{ij}}{\sqrt{E_{ij}}}, \qquad Z = U \Sigma V^\top

読み方：観測と期待の差を、期待の平方根で割る。各セルのズレを揃えた行列。

Z の二乗和が \chi^2。特異値の二乗が各軸の慣性になる。 PCA が共分散行列を分解したように、CA は残差行列を分解する。

導出①：なぜχ²距離なのか

  • アクションとニュースの差が10、マイナーなジャンルの差が10——同じ重みでよい？
  • 列マスで割ると、比率としての逸脱の大きさで公平に比較できる
  • これは「期待度数で正規化する」χ²統計量の発想と同じ

\frac{1}{c_j/N}(\cdots)^2 \;\longleftrightarrow\; \frac{(O-E)^2}{E}

χ²距離を使うからこそ、CAの軸は χ²統計量の分解 と一致する。

導出②：SVDで慣性を軸に分配する

\sum_k \sigma_k^2 = \chi^2 なので総慣性が特異値の二乗に分配される。

\lambda_k = \frac{\sigma_k^2}{N}, \qquad \sum_k \lambda_k = \frac{\chi^2}{N} = \text{総慣性}

読み方：各軸の慣性は、特異値の二乗を全体の度数で割ったもの。総和は総慣性に一致する。

導出③：行座標・列座標を作る

SVD から行と列の2次元座標を取り出す。

\text{行座標} \;\approx\; D_r^{-1/2}\,U\,\Sigma, \qquad \text{列座標} \;\approx\; D_c^{-1/2}\,V\,\Sigma

読み方：行と列の座標は、特異ベクトルに重みと特異値を掛けて作る。

行も列も同じ特異値 \Sigma で重み付けされるので同一平面に置ける。 これが「行と列を同じ図に描ける」根拠である。

アルゴリズム：CAの計算手順

  1. 分割表 O から期待度数 E_{ij}=r_i c_j / N を計算
  2. 標準化残差 Z_{ij}=(O_{ij}-E_{ij})/\sqrt{E_{ij}} を作る
  3. Z を SVD 分解：Z = U\Sigma V^\top
  4. 固有値 \lambda_k=\sigma_k^2/N と 寄与率 を求める
  5. 上位2軸で行座標・列座標を計算し、バイプロットを描く

prince.CA がこの全工程を担います。

解釈①：第1軸が表す意味

折れ線の形が似ている年代ほど、図の上でも近くに来ます。 列どうしの近さも同じ読み方になる。

落とし穴①：近さの解釈を混同しない

近さ 正しい解釈
行 ⇔ 行 行プロファイルが似ている（χ²距離が近い）
列 ⇔ 列 列プロファイルが似ている
行 ⇔ 列 その行がその列を期待より多く選ぶ（過剰選択）

行-列の近さを「同じ距離空間の距離」と読むと誤り。異種点の近接は連想（association）であって距離ではない。

落とし穴②：寄与の小さい次元

低寄与率の軸を過剰に解釈してはいけない。

print(f"2次元の累積寄与率 = {cum[1]:.2f}%   第3軸の寄与率 = {pov[2]:.2f}%")
2次元の累積寄与率 = 97.91%   第3軸の寄与率 = 2.09%

灰色の軸はノイズに近く解釈に値しません。読む前に必ず寄与率を確認する。

落とし穴③：まれなカテゴリの過大な影響

総度数わずか2の「特撮」が図の端まで飛ぶ。列マスは0.5%しかないのに、総慣性の3.8%をこの1点が占める。まれなカテゴリは統合・除外を検討する。

発展①：多重対応分析（MCA）

  • 年齢層 × ジャンル × 居住地——3元のクロス集計をそのままCAにはできない
  • 多重対応分析（MCA）：各カテゴリを0/1のダミーに展開し、その指示行列にCAを適用
  • 多数の質問項目を持つアンケートを、一枚の布置図にまとめられる

MCA は CA の自然な拡張です。次回の解析フローで扱います。

発展②：関連手法との対比

  • χ²検定：関連の有無を検定（CAの入口。有意を確認してからCAで解釈）
  • PCA：連続変数の分散を圧縮（CAはχ²構造を圧縮する「カテゴリ版PCA」）
  • MCA：3変数以上のカテゴリカル（CAの多変量拡張）
  • 対数線形モデル：分割表の関連を統計モデルで定量化

CAは「検定で見えた関連を、地図にして解釈する」道具として使う。

まとめ

今回の3つのポイント

  1. CA＝分割表の標準化残差をSVDで分解し、行と列を同じ平面に置く手法。総慣性 \chi^2/N を軸に分配する。
  2. 行同士・列同士の近さは構成比の類似（χ²距離）。行-列の近さは「期待より多く選ぶ（過剰選択）」を表す——距離ではない。
  3. χ²検定で 有意を確認し、CAで パターンを可視化する。寄与率を必ず確認し、まれなカテゴリに注意する。

今回のデータでは第1軸（81.5%）が「若年×娯楽 ⇔ 高齢×報道」の年齢勾配を捉えた。

  • クロス集計 → χ²検定 → 残差分析 → CA(2変数) → MCA(3変数) を一連の流れで実践
