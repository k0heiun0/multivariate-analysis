第10回 主成分分析（PCA）

数百の変数を人間が解釈できる形にできるか——64次元の手書き数字を2次元に圧縮する

場面：「64個の数字をどう見る？」

8×8の手書き数字画像は、64個の数字の並びです。これを目で見て分類できるでしょうか。

右のように2つ選ぶと重なって見分けがつきません。 64を2に落とす別の道が要ります。

今回の問い

手書き数字認識：各画像は 8×8＝64 ピクセル、すなわち 64 次元 のデータ。

  • 64 次元は人間には直接可視化できない
  • 変数が多すぎると学習も遅く、解釈も困難になる
  • 数百の変数を、人間が解釈できる形に圧縮できるか？

今回は、その答えとなる 主成分分析（PCA） を学ぶ。

具体化①：手書き数字データを見る

digits = load_digits()
X_dig = digits.data          # (1797, 64)
y_dig = digits.target
print(f"標本数={X_dig.shape[0]}, 次元={X_dig.shape[1]}, クラス数={len(np.unique(y_dig))}")
標本数=1797, 次元=64, クラス数=10

データの四角形：1797×64 の行列

上：実データ先頭40行を濃淡で表示。下：その模式図。y の列が無い四角形そのものが今回の対象。

具体化②：64 次元をどう眺めるか

1枚の画像は 64 個の数値の並び。表で見ても構造はつかめない。

  • 2変数なら散布図、3変数なら3D。だが 64 次元は描けない
  • 知りたいのは「どれだけ似ているか」という全体の構造

具体化③：次元の呪い

次元が増えると、すべての点が互いに「等距離」になり、近い・遠いが意味を失う。

距離が「みな同じ」になると、KNN やクラスタリングが効かなくなる。

素朴な方法①：2 ピクセルだけ取り出す

「64個から代表2個だけ選べばいい」——本当にそれで構造が見えるか？

10 クラスが団子状に重なり、まったく分離しない。

素朴な限界：情報を捨てすぎ

  • どの2個を選ぶかに必然性がない
  • 「数字を区別する方向」はピクセルの組み合わせにある

軸を選ぶのではなく作る。 これが PCA の出発点です。

位置づけ：教師なし・次元縮小へ

PCA はラベルを使いません。X の広がりだけから軸を決めます。

直感：分散が最大の方向に射影する

データが最も「広がっている」方向を第1主成分とし、そこに射影する。

PC1 だけで全変動の約 87% を説明できている（この人工データの場合）。

定義①：記号とデータ行列

\mathbf{X} は中心化済みのデータ行列、\mathbf{v} は単位ベクトル。 z_i=\mathbf{v}^\top\mathbf{x}_i が主成分スコア。その分散を最大にしたい。

\text{Var}(z) = \frac{1}{n-1}\sum_{i=1}^n (\mathbf{v}^\top\mathbf{x}_i)^2 = \mathbf{v}^\top \mathbf{S}\,\mathbf{v}

読み方：射影した値の分散は、方向ベクトルを共分散行列で挟んだ形で書ける。

定義②：共分散行列の固有値分解

分散最大化は共分散行列の固有値分解に帰着する。

\mathbf{S} = \frac{1}{n-1}\mathbf{X}^\top\mathbf{X}, \qquad \mathbf{S}\mathbf{v}_k = \lambda_k \mathbf{v}_k

読み方：共分散行列を固有値分解する。固有ベクトルが主成分の向き、固有値がその分散。

  • 固有値＝その方向の分散の大きさ
  • 固有ベクトルは互いに直交する

定義③：主成分スコアと寄与率

\mathbf{Z} = \mathbf{X}\mathbf{V} \quad(\text{各列が PC1, PC2, ... のスコア})

何割を説明するかが寄与率。

r_k = \frac{\lambda_k}{\sum_{j=1}^p \lambda_j}, \qquad \text{累積寄与率} = \sum_{k=1}^{K} r_k

定義④：ラグランジュ未定乗数法

制約 g(\mathbf{v})=0 のもとで f(\mathbf{v}) を最大にするには：

L(\mathbf{v},\lambda) = f(\mathbf{v}) - \lambda\, g(\mathbf{v}), \qquad \partial L/\partial \mathbf{v} = \mathbf{0}

＝ 最適点で \nabla f = \lambda \nabla g（勾配が平行）

定義⑤：特異値分解

どんな n\times p 行列も、次の3つの積に分けられる：

\mathbf{X} = \mathbf{U}\,\mathbf{\Sigma}\,\mathbf{V}^\top

\mathbf{U}^\top\mathbf{U} = \mathbf{I},\quad \mathbf{V}^\top\mathbf{V} = \mathbf{I},\quad \mathbf{\Sigma} = \operatorname{diag}(\sigma_1, \sigma_2, \dots)

  • \mathbf{U}・\mathbf{V} の列：特異ベクトル。直交し長さ 1
  • \sigma_k：特異値。非負で、\sigma_1 \ge \sigma_2 \ge \cdots と大きい順
  • どんな行列も「回転 → 伸縮 → 回転」

導出①：分散最大化を式で書く

第1主成分は次の制約付き最大化で定義される。

\max_{\mathbf{v}} \;\; \mathbf{v}^\top \mathbf{S}\,\mathbf{v} \quad \text{subject to} \quad \mathbf{v}^\top\mathbf{v} = 1

読み方：長さ1という制約のもとで、射影後の分散を最大にする方向を探す。

制約がないと \mathbf{v} を伸ばすだけで分散が増えてしまう。 この最適化をラグランジュ未定乗数法（定義④）で解く。

導出②：ラグランジュ未定乗数法

L(\mathbf{v},\lambda) = \mathbf{v}^\top \mathbf{S}\,\mathbf{v} - \lambda(\mathbf{v}^\top\mathbf{v} - 1)

\frac{\partial L}{\partial \mathbf{v}} = 2\mathbf{S}\mathbf{v} - 2\lambda\mathbf{v} = \mathbf{0} \;\;\Longrightarrow\;\; \boxed{\mathbf{S}\mathbf{v} = \lambda\mathbf{v}}

最適な \mathbf{v} は固有ベクトル、\lambda は固有値。（微分は第1回の定義⑥）

導出③：最大固有値が第1主成分

固有方程式 \mathbf{S}\mathbf{v}=\lambda\mathbf{v} を、最大化したい分散に代入する。

\mathbf{v}^\top \mathbf{S}\,\mathbf{v} = \mathbf{v}^\top (\lambda \mathbf{v}) = \lambda\,\mathbf{v}^\top\mathbf{v} = \lambda

読み方：射影後の分散は、ちょうど固有値そのものに等しい。

  • 分散の最大化＝最大固有値の固有ベクトルを選ぶこと

分散最大化＝固有値分解が代数的に確かめられた。

導出④：数値で確認する

X_std = StandardScaler().fit_transform(X_dig)
S = np.cov(X_std, rowvar=False)
w, V = np.linalg.eigh(S)
order = np.argsort(w)[::-1]
w, V = w[order], V[:, order]
v1 = V[:, 0]
r = np.random.RandomState(0).randn(64)
r = r / np.linalg.norm(r)          # でたらめに選んだ単位ベクトル
print(f"最大固有値 λ1            = {w[0]:.3f}")
print(f"PC1方向に射影した分散    = {(X_std @ v1).var(ddof=1):.3f}")
print(f"（参考）ランダム方向の分散 = {(X_std @ r).var(ddof=1):.3f}")
最大固有値 λ1            = 7.345
PC1方向に射影した分散    = 7.345
（参考）ランダム方向の分散 = 1.549

固有値 7.345 ＝ PC1 方向の分散。ランダム方向（≈1.5）より圧倒的に大きい。

行列で見る：PCA は四角形の分解

\mathbf{Z} = \mathbf{X}\mathbf{V} = \mathbf{U}\mathbf{\Sigma}

導出⑤：SVD との関係

\mathbf{X} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}^\top \;\;\Longrightarrow\;\; \mathbf{S} = \frac{1}{n-1}\mathbf{V}\mathbf{\Sigma}^2\mathbf{V}^\top

\mathbf{V} が主成分方向、スコアは \mathbf{U}\mathbf{\Sigma}。

なぜ SVD のほうが安定か

\mathbf{X}^\top\mathbf{X} を作ると条件数が二乗され、小さな特異値の精度が落ちる。

手順：PCA の計算ステップ

sklearn.decomposition.PCA がこの全工程を担います。

手順：scikit-learn での実行

fit で軸を学習、transform で射影、inverse_transform で復元する。

pca_full = PCA(n_components=64, random_state=42)
pca_full.fit(X_std)
evr = pca_full.explained_variance_ratio_
cum = np.cumsum(evr)
n90 = int(np.searchsorted(cum, 0.90)) + 1
print(f"PC1の寄与率          = {evr[0]:.1%}")
print(f"PC1+PC2の累積寄与率  = {cum[1]:.1%}")
print(f"累積90%に必要な成分数 = {n90}（64次元中）")
PC1の寄与率          = 12.0%
PC1+PC2の累積寄与率  = 21.6%
累積90%に必要な成分数 = 31（64次元中）

PC1 単独で 12.0%、上位2成分で 21.6%。90% には 31 成分が必要。

デモ①：Scree Plot と累積寄与率

各成分の寄与率（Scree Plot）と、その積み上げ（累積寄与率）を描く。

寄与率はなだらかに減衰。10 成分で 58.9%、20 成分で 79.3% を説明する。

デモ②：2D 散布図（クラス色分け）

pca2 = PCA(n_components=2, random_state=42)
Z2 = pca2.fit_transform(X_std)

ラベルを使っていないのに、0・4・6 などが別々の領域へ自然に分かれている。

デモ③：Biplot（変数の寄与）

Biplot は、スコアの散布図に 各元変数（ピクセル）の寄与方向 を矢印で重ねる図。

矢印（負荷量）は「どのピクセルが PC1・PC2 を強く作っているか」を示す。

デモ④：再構成と再構成誤差

K 成分で射影して戻すと、どこまで復元できるか。

ks = [2, 5, 10, 20, 30]
pcas = [PCA(n_components=k, random_state=42).fit(X_std) for k in ks]
errs = [np.mean((X_std - q.inverse_transform(q.transform(X_std))) ** 2) for q in pcas]
print("  ".join(f"K={k}: 誤差={e:.3f}" for k, e in zip(ks, errs)))
K=2: 誤差=0.747  K=5: 誤差=0.559  K=10: 誤差=0.392  K=20: 誤差=0.197  K=30: 誤差=0.102

成分を増やすほど誤差は単調に減る（K=2→0.747, K=20→0.197, K=30→0.102）。

解釈①：Scree Plot の読み方

  • 肘（エルボー）：寄与率が急減から緩やかに変わる点
  • 累積寄与率の閾値：80%・90% で決める

可視化（2D）か圧縮（90%）かで、残す成分数は変わります。

解釈②：2D 散布図から何が言えるか

PC1・PC2 平面での各数字の重心を調べる。

for d in [0, 4, 6, 7]:
    m = y_dig == d
    print(f"数字{d}: PC1平均={Z2[m,0].mean():+.2f}, PC2平均={Z2[m,1].mean():+.2f}")
数字0: PC1平均=-1.63, PC2平均=-1.95
数字4: PC1平均=-4.65, PC2平均=-0.36
数字6: PC1平均=-1.31, PC2平均=-3.88
数字7: PC1平均=-0.83, PC2平均=+3.84

PC1・PC2 は「数字の形の大きな違い」を捉える軸になっている。

解釈③：負荷量と主成分の意味

主成分はピクセルの重み付き和。負荷量を画像化する。

各 PC は数字全体に広がる濃淡の対比。

2 本の軸が数字の形の違いを捉えた——ただ、これらの解釈には落とし穴があるかもしれない。

落とし穴①：標準化の要否

PCA は分散最大化なので、変数のスケールに強く依存する。

# 生データ（標準化なし）と標準化ありで、PC1 の寄与率を比べる
r_raw = PCA(n_components=2).fit(X_dig).explained_variance_ratio_[0]
r_std = PCA(n_components=2).fit(X_std).explained_variance_ratio_[0]
print(f"PC1寄与率  なし={r_raw:.1%}  あり={r_std:.1%}")
PC1寄与率  なし=14.9%  あり=12.0%
  • 単位がバラバラなら標準化が必須
  • 同じ単位（画像のピクセル等）なら生のままも妥当

落とし穴②：分散最大 ≠ 分類に有用

PCA はラベルを見ない。分散が大きい方向が分離の方向とは限らない。

クラスを分けるのは横軸（分散小）。クラス分離が目的なら LDA を使う。

落とし穴③：解釈と線形性の限界

PCA には、結果の使い方に関わる本質的な制約がある。

  • 解釈が難しい：主成分は全変数の線形結合
  • 線形変換のみ：曲がった構造は展開できない
  • 外れ値に弱い：極端な点が方向を引っ張る

発展①：カーネル PCA

  • データを高次元空間へ写してから PCA を行う（カーネルトリックで明示的計算を回避）
  • 円環・同心円・スイスロールなど、線形 PCA では展開できない構造を分離できる
  • 代償：カーネルとパラメータの選択が必要、n\times n 行列で大規模データは重い

sklearn.decomposition.KernelPCA で kernel='rbf' などを指定して使う。

発展②：t-SNE・UMAP（次回予告）

可視化に特化した非線形次元縮小として t-SNE と UMAP がある。

  • 近傍の保存：近い点どうしの関係を保ち、クラスタを際立たせる
  • PCA より分離の良い2D 図になることが多い（軸に意味はない）
  • 距離や大域構造は保存されず、乱数に依存する

圧縮・前処理なら PCA、可視化なら t-SNE/UMAP。

まとめ

今回の3つのポイント

  1. PCA ＝分散が最大の直交方向を順に求める線形変換。\mathbf{S}\mathbf{v}_k=\lambda_k\mathbf{v}_k。
  2. ラグランジュ未定乗数法で「分散最大化＝最大固有値の固有ベクトル」が導かれ、寄与率 r_k=\lambda_k/\sum\lambda_j で残す次元を決める。
  3. 線形・教師なしなので、非線形構造やクラス分離には限界がある（カーネルPCA・t-SNE へ）。
