y が無ければ、X 自身を近似する

第I部　理論

前回まで：yと比べていた

\begin{aligned} &\text{第1回：}\ \lVert\boldsymbol y-\mathbf X\boldsymbol\beta\rVert_2^2\\ &\text{第6回：}\ \textstyle\sum_i\bigl[y_i\log\theta_i+(1-y_i)\log(1-\theta_i)\bigr]\\ &\text{第7回：}\ \textstyle\frac1n\sum_i\bigl[c_{\mathrm{FN}}\,y_i(1-\hat y_i)+c_{\mathrm{FP}}\,(1-y_i)\,\hat y_i\bigr] \end{aligned}

第1回の地図に「近似する相手」の列を足す。今回はその境目の回。

次の問い：何を近似するか

  • これまでのモデルは、答えの列 y を \mathbf X から作った
  • y が無ければ、近似する相手として残るのは \mathbf X だけ

問い：\mathbf X を、何で近似すればよいか？使いどころ：似た商品や客をまとめる。多くの列を少数の軸に縮める。

モデル①：yをXで近似する

第1〜7回。データ行列 \mathbf X の横に答えの列 \boldsymbol y がある。モデルは \boldsymbol y を \mathbf X から作る。

モデル②：残るのはXだけ

\boldsymbol y の列を消すと、データ行列 \mathbf X だけが残る。近似する相手も \mathbf X になる。

小さな例：おにぎり30個

人工データ。店の印の無いおにぎり30個の幅と高さ（cm）。1個が \mathbf X の1行。

k-means①：3つの群に分ける

形の似たものどうしで、30個を3つの群に分ける。

k-means②：群に代表点を置く

群ごとに代表点★を1つ置く。★は、群の点の平均の位置。

k-means③：点を★で近似する

各点を、自分の群の★で近似する。灰色の線が近似の誤差。第1回で見たk-means。

主成分分析①：1本の軸を引く

同じ30個。今度は代表点の代わりに、点の中心を通る1本の軸を引く。

主成分分析②：点を軸で近似する

各点を、軸に下ろした足（赤い点）で近似する。灰色の線が誤差。軸が1本の主成分分析。

モデル③：XをXで近似する

どちらも \mathbf X の各行を、\mathbf X から作った点で近似する。y はどこにも出てこない。

困りごと①に戻る

分ける基準は、\mathbf X をどれだけよく近似できるか。灰色の誤差の線が短くなるように、群と代表点を決める。

次の問い：誤差をどう足すか

  • 回帰の誤差は、1行に1つの数だった
  • k-meansの誤差は、点から代表点への線。1点が p 個の成分を持つ

問い：\mathbf X を近似した誤差を、どう1つの数にまとめるか？使いどころ：1行に何個もある誤差を、1つの目的関数にする。

目的関数①：yを近似する

\sum_{i=1}^{n}\Bigl(y_i-\sum_{j=1}^{p}\beta_j x_{ij}\Bigr)^2

第1回の回帰。たとえば幅から高さを当てる。誤差は縦の線で、1行に1つの数。

回帰をベクトルで書く

\begin{aligned} &\sum_{i=1}^{n}\Bigl(y_i-\sum_{j=1}^{p}\beta_j x_{ij}\Bigr)^2\\ &=\lVert\boldsymbol y-\mathbf X\boldsymbol\beta\rVert_2^2 \end{aligned}

n 本の縦の線を並べたベクトルの、\ell_2 ノルムの二乗。

k-means：1点の誤差

\begin{aligned} &\bigl(x_{i1}-c_{q(i)\,1}\bigr)^2\\ &\quad+\bigl(x_{i2}-c_{q(i)\,2}\bigr)^2 \end{aligned}

点 i の誤差は、代表点までの線の長さの二乗。幅の差の二乗と高さの差の二乗の和。

目的関数②：Xを1マスずつ

\sum_{i=1}^{n}\sum_{j=1}^{p}\bigl(x_{ij}-c_{q(i)\,j}\bigr)^2

k-means。q(i) は行 i の群、c_{qj} は群 q の代表点の第 j 成分。誤差は1マスに1つ。n\times p 個の二乗の和。

目的関数③：1行ずつまとめる

\begin{aligned} &\sum_{i=1}^{n}\sum_{j=1}^{p}\bigl(x_{ij}-c_{q(i)\,j}\bigr)^2\\ &=\sum_{i=1}^{n}\bigl\lVert\tilde{\boldsymbol x}_i-\boldsymbol c_{q(i)}\bigr\rVert_2^2 \end{aligned}

内側の和（右の棒）は、行と代表点の距離の二乗。第1回のk-meansの式。

次の問い：行列で書けるか

  • 回帰は \lVert\boldsymbol y-\mathbf X\boldsymbol\beta\rVert_2^2 と、行列とベクトルで書けた
  • k-meansの式には、添え字に群の番号 q(i) が入っている
  • 行列の大きさを測る道具と、所属を行列で書く道具を用意する

問い：k-meansの目的関数も、行列で書けるか？使いどころ：回帰と同じ形で並べて比べる。

道具①：行列の大きさの例

\begin{aligned} \mathbf E&=\begin{bmatrix}3&-1\\0&2\end{bmatrix}\\ &\longrightarrow\ 3^2+(-1)^2+0^2+2^2=14 \end{aligned}

誤差の行列の大きさを、全マスの二乗を足して1つの数にする。

道具①：フロベニウスノルム

\lVert\mathbf E\rVert_F^2=\sum_{i=1}^{n}\sum_{j=1}^{p}e_{ij}^2

行列の全マスの二乗和。\lVert\mathbf E\rVert_F をフロベニウスノルムと呼ぶ。

道具①：行ごとに足しても同じ

\lVert\mathbf E\rVert_F^2=\sum_{i=1}^{n}\lVert\tilde{\boldsymbol e}_i\rVert_2^2

行ごとの \ell_2 ノルムの二乗を足したもの。例では 10+4=14。1列の行列（ベクトル）なら \lVert\boldsymbol e\rVert_2^2 に戻る。

道具②：所属を0と1で書く

\mathbf G=\begin{bmatrix}1&0\\0&1\\1&0\\0&1\end{bmatrix}

4行を2群に分ける。1・3行目が群1、2・4行目が群2。\mathbf G（n\times k）の行 i は、群 q(i) の列だけが1。

道具②：代表点を行に並べる

\mathbf C=\begin{bmatrix}\boldsymbol c_1^\top\\ \boldsymbol c_2^\top\end{bmatrix}

\mathbf C（k\times p）の第 q 行は、群 q の代表点。

道具②：GCは各行の代表点

\mathbf G\mathbf C=\begin{bmatrix}1&0\\0&1\\1&0\\0&1\end{bmatrix} \begin{bmatrix}\boldsymbol c_1^\top\\ \boldsymbol c_2^\top\end{bmatrix} =\begin{bmatrix}\boldsymbol c_1^\top\\ \boldsymbol c_2^\top\\ \boldsymbol c_1^\top\\ \boldsymbol c_2^\top\end{bmatrix}

\mathbf G\mathbf C の第 i 行は \boldsymbol c_{q(i)}^\top。行 i の代表点が並ぶ。

道具②：箱で見る

\mathbf G は n\times k、\mathbf C は k\times p。積 \mathbf G\mathbf C は n\times p で、\mathbf X と同じ大きさ。

道具がそろった

  • フロベニウスノルム \lVert\mathbf E\rVert_F^2：行列の全マスの二乗和
  • 所属行列 \mathbf G と代表点の行列 \mathbf C：\mathbf G\mathbf C の各行が代表点

これで、k-meansの目的関数を行列で書ける。

目的関数④：行列で書く

\begin{aligned} &\sum_{i=1}^{n}\sum_{j=1}^{p}\bigl(x_{ij}-c_{q(i)\,j}\bigr)^2\\ &=\lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2 \end{aligned}

右の図の行列が \mathbf X-\mathbf G\mathbf C。第 i 行は \tilde{\boldsymbol x}_i-\boldsymbol c_{q(i)}。同じ式を行列1つで書いた。

k-meansを箱で見る

\mathbf X（n\times p）を、所属 \mathbf G（n\times k）と代表点 \mathbf C（k\times p）の積で近似する。

主成分分析：1マスずつ

\sum_{i=1}^{n}\sum_{j=1}^{p}\Bigl(x_{ij}-\sum_{m=1}^{Q}f_{im}\,a_{jm}\Bigr)^2

f_{im} は行 i の軸 m の得点、a_{jm} は軸 m の第 j 成分。Q=1 なら右の1本の軸。

目的関数⑤：主成分分析も同じ形

\sum_{i=1}^{n}\sum_{j=1}^{p}\Bigl(x_{ij}-\sum_{m=1}^{Q}f_{im}\,a_{jm}\Bigr)^2 =\lVert\mathbf X-\mathbf F\mathbf A^\top\rVert_F^2

得点 \mathbf F（n\times Q）と軸 \mathbf A（p\times Q）。軸は長さ1で互いに直角（\mathbf A^\top\mathbf A=\mathbf I_Q）。

主成分分析を箱で見る

\mathbf X（n\times p）を、得点 \mathbf F（n\times Q）と軸 \mathbf A^\top（Q\times p）の積で近似する。k-meansと同じ形。

3つの目的関数を並べる

\lVert\boldsymbol y-\mathbf X\boldsymbol\beta\rVert_2^2,\qquad \lVert\mathbf X-\mathbf F\mathbf A^\top\rVert_F^2,\qquad \lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2

どれも「データ − モデル」の二乗和。3つとも最小二乗法。

yが入るのは1つだけ

\lVert\boldsymbol y-\mathbf X\boldsymbol\beta\rVert_2^2,\qquad \lVert\mathbf X-\mathbf F\mathbf A^\top\rVert_F^2,\qquad \lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2

\boldsymbol y が入るのは1つ目だけ。2つ目と3つ目は \mathbf X だけで書ける。

定義①：教師あり学習

  • 目的関数が y を含む
  • y を \mathbf X から近似して、パラメータを決める

回帰、LDA、ロジスティック回帰。第1〜7回はすべてこちら。

定義②：教師なし学習

  • 目的関数が \mathbf X だけで書ける
  • \mathbf X を \mathbf X 自身から近似して、パラメータを決める

分かれ目は手法の名前ではなく、目的関数に y があるか。推定法はどちらも最小二乗法を使える。

たとえ：写真の整理

札付きの写真なら、当たったかを札で確かめられる。札の無い写真の山には「山1」としか書けず、名前は見た人が付ける。

次の問い：単位を変えると？

  • J は、列ごとの差の二乗を足していた
  • 重さをgで、高さをcmで測ると、差の桁がまるで違う

問い：列の単位を変えると、答えは変わるか？（困りごと②）使いどころ：成分・金額・個数など、単位のまちまちな列を分けるとき。

人工データ：重さと高さ

2つの型（高さ7cmと10cm）で握ったおにぎり80個。重さはgで測り、ばらつきが大きい（標準偏差 16 g）。

元の単位のまま分ける

k-meansで2つに分けると、群は重さで縦に切られた。型との一致は 51%。

標準化してから分ける

列を標準化してから分けると、高さの2段に分かれる。型との一致は 100%。

式で見る：単位は列の重み

\begin{aligned} &x_{ij}\to s\,x_{ij}\ \ (\text{列}\ j\ \text{だけ})\\ &\Longrightarrow\ \sum_{i=1}^{n}\bigl(s\,x_{ij}-s\,c_{q(i)j}\bigr)^2=s^2\sum_{i=1}^{n}\bigl(x_{ij}-c_{q(i)j}\bigr)^2 \end{aligned}

列 j の単位を s 倍すると、J の中で列 j の重さが s^2 倍になる。cmをmmにすれば100倍。

回帰なら答えは変わらない

x_{ij}\to s\,x_{ij} \quad\Longrightarrow\quad \hat\beta_j\to\hat\beta_j/s,\qquad \mathbf X\hat{\boldsymbol\beta}\ \text{は同じ}

回帰は y を近似する。係数が単位を打ち消すので、予測も誤差も変わらない。\mathbf X を近似すると、ものさしそのものが単位で変わる。

標準化は1つの選択

標準化は「どの列も同じ重さで数える」と決めること。中立な既定値ではない。第7回の0.5と同じく、黙って置く仮定。

困りごと②に戻る

単位は J の中の列の重み。(a) と (b) は、列の重みの決め方が違う2つの答え。どちらを採るかは、重みを決める人の判断。

次の問い：どう解くか

  • 3つの目的関数が、同じ形で書けた
  • 回帰は、正規方程式を1回解けば答えが出た

問い：教師なしの目的関数は、何を未知として解くのか？使いどころ：未知が2つの行列の積になる問題。

解き方①：回帰は未知が1つ

未知は \boldsymbol\beta だけ（薄い赤）。\mathbf X はデータとして与えられている。勾配を0とおき、正規方程式を1回解く。

解き方②：未知が2つの積

k-meansでは \mathbf G も \mathbf C も未知。モデルは未知どうしの積。主成分分析の \mathbf F と \mathbf A も同じ。

解き方③：片方を固定する

\mathbf G を固定すれば、\mathbf C についての最小二乗になる。\mathbf C を固定すれば \mathbf G について解ける。2つを交互に解き直す。

アルゴリズム①：教師あり

  1. 用意する：\mathbf X と \boldsymbol y。訓練の行とテストの行に分ける（第2回）
  2. 解く：訓練の行で \mathbf X^\top\mathbf X\boldsymbol\beta=\mathbf X^\top\boldsymbol y
  3. 出す：\hat{\boldsymbol y}=\mathbf X_{\text{テスト}}\hat{\boldsymbol\beta}
  4. 測る：\boldsymbol y_{\text{テスト}} と \hat{\boldsymbol y} を比べる

アルゴリズム②：教師なし

  1. 用意する：\mathbf X だけ
  2. 解く：\lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2 を \mathbf G,\mathbf C について最小に
  3. 出す：\mathbf G（所属）、\mathbf C（代表点）、J の値
  4. 測る：？

アルゴリズム：計算の手順

教師あり（回帰） 教師なし（k-means）
1. 用意する \mathbf X と \boldsymbol y。訓練とテストの行に分ける \mathbf X だけ
2. 解く 訓練の行で \mathbf X^\top\mathbf X\boldsymbol\beta=\mathbf X^\top\boldsymbol y \lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2 を \mathbf G,\mathbf C について最小に
3. 出す \hat{\boldsymbol y}=\mathbf X_{\text{テスト}}\hat{\boldsymbol\beta} \mathbf G（所属）、\mathbf C（代表点）、J の値
4. 測る \boldsymbol y_{\text{テスト}} と \hat{\boldsymbol y} を比べる 比べる y が無い。J と、\mathbf C を人が読むこと

4段目に、比べる相手の y が無い。

最後の問い：何で測るか

  • 目的関数から y が消えた
  • 教師ありでは、テストの行の正解と照らして測った（第2回）

問い：y が無いとき、答えの良し悪しを何で測るか？使いどころ：分けた結果を人に報告する前に。（困りごと③）

帰結①：教師ありなら照らせる

\lVert\boldsymbol y_{\text{テスト}}-\mathbf X_{\text{テスト}}\hat{\boldsymbol\beta}\rVert_2^2

テストの行の正解と照らして、手元に無い行への当たり方を測れる（第2回）。

帰結①：照らす相手が無い

J=\lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2

J は \mathbf X とモデルの距離。外に正解が無い。J が小さいことは、「\mathbf X をよく近似した」ことしか意味しない。

帰結②：群に番号が付く

k-meansの答えには、群1・群2・群3と番号が付いて返ってくる。

帰結②：番号を付け替える

番号（と色）だけを付け替えた。代表点の位置も、灰色の線の長さも変わらない。J も同じ。

帰結②：番号を付け替えても同じ

\lVert\mathbf X-\mathbf G\mathbf P\,\mathbf P^\top\mathbf C\rVert_F^2=\lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2

\mathbf P は列の並べ替え（\mathbf P\mathbf P^\top=\mathbf I_k）。番号を付け替えても J は同じ。番号に意味は無い。

帰結③：群の数を変えてJを測る

おにぎり30個で、群の数 k を1から8まで変える。J の最小値は下がり続ける。

帰結③：なぜ下がるか

  • k 群の答えに群を1つ足し、どれかの点をそこへ移す
  • 移した点の誤差は0になる。ほかの点はそのままでよい
  • だから J の最小値は、下がるか変わらない

k=n なら、全点が自分自身を代表点にでき、J=0。

帰結③：群を増やせばJは下がる

J が小さい k を選ぶと、いつも大きい k になる。J だけでは群の数を選べない。

帰結④：2つの店のおにぎり

人工データ。y は店（店Aが90個、店Bが60個）。どちらの店も、大きいおにぎりほど幅も高さも大きい。

帰結④：店の2群でJを測る

★は店ごとの平均。★を代表点にした J も計算できる。

帰結⑤：Jの最小はyの群でない

y を使わずに J を最小にした2群が (b)。J は (b) のほうが小さい。

帰結⑤：雲を長い向きで切る

J は細長い雲を長い向きの途中で切るほうが小さい。y との一致は 61%。J の最小は y を知らない。

帰結⑥：評価の根拠を並べる

教師あり 教師なし
目的関数 \lVert\boldsymbol y-\mathbf X\boldsymbol\beta\rVert_2^2（y を含む） \lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2、\lVert\mathbf X-\mathbf F\mathbf A^\top\rVert_F^2
測る相手 テストの行の正解 y 無い（J の値と人の読み方）
出力の番号 「品種1」など、外で決まった意味 付け替えても J は同じ。意味は人が付ける
大きさを増やすと テストの誤差はいずれ上がる（第2回） J は下がり続ける
テストの行で測ると 誤差に谷が出て、大きさを選べる J は下がり続け、谷が出ない
列の単位を変えると 係数が打ち消し、予測は同じ 列の重みが変わり、答えも変わる

次の問い：テストの行で測れば？

  • J は、訓練の行では群の数とともに下がり続けた
  • 第2回の回帰では、テストの行で測ると誤差に谷が出た

教師なしでも、分けて測れば群の数を選べるか？（困りごと③）使いどころ：群の数を決めたいとき。

第2回の谷

回帰では、モデルを大きくしすぎると、テストの誤差が上がった。谷の位置で大きさを選べた。

テストの行のJ

\begin{aligned} J_{\text{テスト}}&=\frac{1}{n_{\text{テスト}}}\sum_{i\in\text{テスト}}\\ &\quad\min_{q}\bigl\lVert\tilde{\boldsymbol x}_i-\boldsymbol c_q\bigr\rVert_2^2 \end{aligned}

代表点は訓練の行で決める。テストの行（黒い輪）は、いちばん近い代表点で近似する。

谷が出ない

テストの行の J も、k とともに下がり続ける（5.58 → 0.30）。k=3 の後は下がり方が緩むだけで、谷は無い。

なぜ谷が出ないか

  • 回帰：訓練の y の偶然の揺れまで追うと、テストの y では外れる
  • k-means：代表点は点の雲の中に置かれる。テストの行も同じ雲から来る
  • 代表点を増やせば、テストの行の近くにも代表点が増える

分けて測っても、J だけでは群の数を選べない。

困りごと③に戻る

訓練の行の J も、テストの行の J も、2つより3つ、3つより4つを良いと言う。群の数は J の外で決める。

たとえ：バス停を置く

バス停を増やすほど、新しく越してきた家からも歩く距離は短くなる。何個置くかは、歩く距離だけでは決まらない。

締め

まとめ①：Xを近似する

y が無ければ \mathbf X 自身を近似する。k-meansは \lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2、主成分分析は \lVert\mathbf X-\mathbf F\mathbf A^\top\rVert_F^2。

まとめ②：推定法は同じ

どれも最小二乗法。教師ありと教師なしの違いは、目的関数に y が入るかどうかだけ。

まとめ③：正解と照らせない

J は番号を付け替えても同じで、k とともに下がる（テストの行でも）。y の群を選ぶとは限らない。列の単位が答えを変える。

次回予告①：Xを軸で近似する

\min_{\mathbf F,\mathbf A}\ \lVert\mathbf X-\mathbf F\mathbf A^\top\rVert_F^2 \qquad\text{ただし}\ \mathbf A^\top\mathbf A=\mathbf I_Q

今回は目的関数を書いただけ。まだ解いていない。

次回予告②：未知が2つの積

\mathbf F も \mathbf A も未知で、モデルはその積になっている。

次回予告③：どう解くか

  • 回帰なら正規方程式を1回解けばよかった
  • 未知が2つの積なら、片方ずつ解けるか
