モデル①：第6回のLDA

\Pr(g_{iq}=1)=\pi_q\qquad(\pi_1+\pi_2=1)

まず群を選ぶ。卵なら、M玉かL玉か。g_{iq} は第7回のメンバーシップ関数。

モデル①：群の中で散らばる

選んだ群の中で、重さが正規分布に従って散らばる。第6回はこの状態で推定した。

モデル②：所属を隠す

1つのかごに混ざると、見えるのは重さ x だけ。どちらの群から出たかは分からない。

定義：混合正規分布

2つの山を割合 \pi_q で重み付けて足した分布を、混合正規分布と呼ぶ。\pi_q を混合比率と呼ぶ。

2変数の例：浜辺で拾った貝殻120個の長さと高さ。行 i はベクトル \tilde{\boldsymbol x}_i（第7回と同じ記号）。

モデル③：Σは群ごとでよい

問い：所属が見えないとき、対数尤度はどんな形になるか？

目的関数①：1点の出やすさ

f(\tilde{\boldsymbol x}_i)=\sum_{q=1}^{k}\pi_qN(\tilde{\boldsymbol x}_i;\boldsymbol\mu_q,\boldsymbol\Sigma_q)

行 i の出やすさ。どの群から出たか分からないので、k 本の道の確率を足す。卵なら \pi_1f_1(x_i)+\pi_2f_2(x_i)。

目的関数②：対数尤度

\ell=\sum_{i=1}^{n}\log\sum_{q=1}^{k}\pi_qN(\tilde{\boldsymbol x}_i;\boldsymbol\mu_q,\boldsymbol\Sigma_q)

行が独立なら、全体の出やすさは積。対数をとると和になる（第6回）。

目的関数②：logの中に和

\ell=\sum_{i=1}^{n}\log\Bigl(\underbrace{\textstyle\sum_{q=1}^{k}\pi_qN(\tilde{\boldsymbol x}_i;\boldsymbol\mu_q,\boldsymbol\Sigma_q)}_{\text{logの中の和}}\Bigr)

ただし、logの中に和が残る。\boldsymbol\mu_1 を動かすと、この和全体が変わる。

目的関数③：所属が見えていれば

\ell_{\mathbf G}=\sum_{i=1}^{n}\sum_{q=1}^{k}g_{iq}\Bigl[\log\pi_q+\log N(\tilde{\boldsymbol x}_i;\boldsymbol\mu_q,\boldsymbol\Sigma_q)\Bigr]

第6回の同時の尤度。1が立った群の項だけが残り、和はlogの外に出る。

目的関数③：一度には解けない

和の位置 解き方
所属が見えている（第6回） logの外 群ごとに分かれ、数えて解けた
所属が見えない（今回） logの中 分かれない。偏微分して0とおいても閉じた式にならない

目的関数④：行列で

n\times k の行列 \boldsymbol\Phi を置く。

\begin{aligned} \phi_{iq}&=\pi_qN(\tilde{\boldsymbol x}_i;\boldsymbol\mu_q,\boldsymbol\Sigma_q)\\ \ell&=\mathbf 1_n^\top\log\bigl(\boldsymbol\Phi\mathbf 1_k\bigr) \end{aligned}

\boldsymbol\Phi\mathbf 1_k の第 i 成分が、行 i の出やすさ。logは成分ごとにとる。

責任度

r_{iq}=\Pr(g_{iq}=1\mid\tilde{\boldsymbol x}_i)=\frac{\pi_qf_q(\tilde{\boldsymbol x}_i)}{\sum_{l=1}^{k}\pi_lf_l(\tilde{\boldsymbol x}_i)}

\tilde{\boldsymbol x}_i を見たうえで群 q である確率（事後確率）。群 q が行 i を説明する責任の大きさと見て、責任度と呼ぶ。

たとえ：どんぐりはどの木から

拾ったどんぐりが、どちらの木から落ちたかは見えない。木からの近さと、木の大きさ（落とす数）から「木Bのものが8割」と確率で言う。これが責任度。

見えないgの期待値

\mathbb E[g_{iq}\mid\tilde{\boldsymbol x}_i]=1\cdot r_{iq}+0\cdot(1-r_{iq})=r_{iq}

g_{iq} は0か1。期待値は1をとる確率に等しい。責任度は、見えない g_{iq} の期待値でもある。

責任度行列R

\mathbf R=\operatorname{diag}\bigl(\boldsymbol\Phi\mathbf 1_k\bigr)^{-1}\boldsymbol\Phi

責任度を n\times k に並べる。分子は \boldsymbol\Phi の (i,q) 成分、分母はその行の和。\boldsymbol\Phi の各行を行の和で割ればよい。

道筋：平均の更新

\hat{\boldsymbol\mu}_q=\frac{1}{n_q}\sum_{i=1}^{n}r_{iq}\tilde{\boldsymbol x}_i,\qquad \hat{\mathbf C}=\operatorname{diag}(n_1,\dots,n_k)^{-1}\mathbf R^\top\mathbf X

終着駅はこの更新式。責任度で重み付けた平均。

  1. \ell を \boldsymbol\mu_q で微分すると、責任度が現れる
  2. 0とおくと、責任度で重み付けた平均
  3. 右辺にも \boldsymbol\mu_q がある：\mathbf R を固定して交互に解く
  4. 行列で：第7回の \hat{\mathbf C} の \mathbf G を \mathbf R に

logと密度を微分する計算は、読み物（pdf）に書いた。

平均の更新①：責任度が現れる

責任度 → 重み付きの平均 → 交互に → 行列で

\frac{\partial\ell}{\partial\boldsymbol\mu_q}=\sum_{i=1}^{n}r_{iq}\,\boldsymbol\Sigma_q^{-1}(\tilde{\boldsymbol x}_i-\boldsymbol\mu_q)

logの中の和を微分すると、行 i の項に「群 q から出た確率」r_{iq} が掛かる。第6回のLDAの勾配で、所属の0/1が掛かっていた所。

平均の更新②：重み付きの平均

責任度 → 重み付きの平均 → 交互に → 行列で

\hat{\boldsymbol\mu}_q=\frac{1}{n_q}\sum_{i=1}^{n}r_{iq}\tilde{\boldsymbol x}_i,\qquad n_q=\sum_{i=1}^{n}r_{iq}

勾配を0とおいた答え。n_q は群 q の実質の人数。r_{iq} が0か1なら、第7回の群の平均に戻る。

平均の更新③：交互に解く

責任度 → 重み付きの平均 → 交互に → 行列で

右辺の r_{iq} も \boldsymbol\mu_q を含むので、閉じた式ではない。今の値で r_{iq} を計算して固定し、平均を更新する。第7回の交互最小二乗法と同じ考え方。

平均の更新④：行列で

責任度 → 重み付きの平均 → 交互に → 行列で

\hat{\mathbf C}=\operatorname{diag}(n_1,\dots,n_k)^{-1}\mathbf R^\top\mathbf X

\mathbf R^\top\mathbf X の第 q 行は、各行を責任度で重み付けて足したもの。第7回の (\mathbf G^\top\mathbf G)^{-1}\mathbf G^\top\mathbf X の \mathbf G を \mathbf R に替えた形。

割合の更新

\hat\pi_q=\frac{n_q}{n}

和が1の制約のもとで \pi_q について最大にした答え（計算は読み物）。責任度で数えた群の割合。第6回のコインと同じく、数えた割合がそのまま答え。

共分散の更新

\hat{\boldsymbol\Sigma}_q=\frac1{n_q}\sum_{i=1}^{n}r_{iq}(\tilde{\boldsymbol x}_i-\hat{\boldsymbol\mu}_q)(\tilde{\boldsymbol x}_i-\hat{\boldsymbol\mu}_q)^\top

\boldsymbol\Sigma_q で偏微分して0とおき、\mathbf R を固定して解いた結果（行列での微分は第6回と同じく結果だけ）。群ごとの重み付きの共分散。共通の \boldsymbol\Sigma にするなら \sum_q(n_q/n)\hat{\boldsymbol\Sigma}_q。

次の問い：どう計算するか

  • \mathbf R を固定すれば、\pi_q・\mathbf C・\boldsymbol\Sigma_q は重み付きの式で解ける
  • \mathbf R は、今のパラメータからベイズの定理で計算できる

この2つの更新を、行列の計算の手順にまとめる。

Eステップ：Rを計算する

\begin{aligned} &\phi_{iq}=\pi_qN(\tilde{\boldsymbol x}_i;\boldsymbol\mu_q,\boldsymbol\Sigma_q)\quad(\boldsymbol\Phi\ \text{は}\ n\times k)\\ &\mathbf R\leftarrow\operatorname{diag}(\boldsymbol\Phi\mathbf 1_k)^{-1}\boldsymbol\Phi,\qquad \ell=\mathbf 1_n^\top\log(\boldsymbol\Phi\mathbf 1_k) \end{aligned}

見えない g_{iq} を期待値 r_{iq} で置き換える。期待値（expectation）のE。

Mステップ：重み付きで推定

\begin{aligned} &(n_1,\dots,n_k)^\top=\mathbf R^\top\mathbf 1_n,\qquad \pi_q\leftarrow n_q/n\\ &\mathbf C\leftarrow\operatorname{diag}(n_1,\dots,n_k)^{-1}\mathbf R^\top\mathbf X\\ &\boldsymbol\Sigma_q\leftarrow\tfrac1{n_q}(\mathbf X-\mathbf 1_n\boldsymbol\mu_q^\top)^\top\operatorname{diag}(\boldsymbol r_q)(\mathbf X-\mathbf 1_n\boldsymbol\mu_q^\top) \end{aligned}

\boldsymbol r_q は \mathbf R の第 q 列。重み付きの対数尤度を最大にする。最大化（maximization）のM。

アルゴリズム：EM

  1. 用意する：データ行列 \mathbf X（n\times p）と群の数 k
  2. 初期値：\mathbf C は \mathbf X の行から k 行を無作為に選ぶ。\boldsymbol\Sigma_q は \mathbf X 全体の共分散行列、\pi_q=1/k
  3. Eステップ：\phi_{iq}=\pi_qN(\tilde{\boldsymbol x}_i;\boldsymbol\mu_q,\boldsymbol\Sigma_q)、\mathbf R\leftarrow\operatorname{diag}(\boldsymbol\Phi\mathbf 1_k)^{-1}\boldsymbol\Phi、\ell=\mathbf 1_n^\top\log(\boldsymbol\Phi\mathbf 1_k)
  4. Mステップ：(n_1,\dots,n_k)^\top=\mathbf R^\top\mathbf 1_n、\pi_q\leftarrow n_q/n、\mathbf C\leftarrow\operatorname{diag}(n_1,\dots,n_k)^{-1}\mathbf R^\top\mathbf X、 \boldsymbol\Sigma_q\leftarrow\frac1{n_q}(\mathbf X-\mathbf 1_n\boldsymbol\mu_q^\top)^\top\operatorname{diag}(\boldsymbol r_q)(\mathbf X-\mathbf 1_n\boldsymbol\mu_q^\top)（\boldsymbol r_q は \mathbf R の第 q 列）
  5. 収束判定：\ell の増え方が十分小さければ止める。そうでなければ3へ
  6. ランダムスタート：2〜5を何通りかの初期値で行い、\ell が最も大きい答えを採る

木の場所がわからなくても、仮の場所から各どんぐりの確率を出し（E）、その確率で重みを付けて木の場所を測り直す（M）。これを繰り返す。

次の問い：ℓは上がるか

  • 第7回のk-meansでは、\mathbf G の更新も \mathbf C の更新も J そのものを最小にした。だから J は毎回下がった
  • EMのMステップが最大にするのは、\mathbf R を固定した重み付きの対数尤度。\ell そのものではない

問い：それでも \ell は毎回上がるか？

卵で見る：ℓは下がらない

卵で見る：平らな所

道筋：ℓは下がらない

\ell(\boldsymbol\theta^{(t+1)})\ \ge\ \ell(\boldsymbol\theta^{(t)})

終着駅はこの不等式。\boldsymbol\theta は \pi_q・\mathbf C・\boldsymbol\Sigma_q をまとめた記号、t は反復の回数。

  1. Jensenの不等式で、\ell の下界 L(\mathbf R,\boldsymbol\theta) を作る
  2. Eステップの \mathbf R では、下界が \ell に接する
  3. Mステップは、下界を上げる
  4. 2つを並べて、\ell をはさむ

導出の道具：Jensenの不等式

\begin{gathered} \log\Bigl(\sum_{q}w_qa_q\Bigr)\ge\sum_{q}w_q\log a_q\\ (w_q\ge0,\ \textstyle\sum_qw_q=1,\ a_q>0) \end{gathered}

logは上に凸なので、平均のlogはlogの平均以上。等号は a_q がすべて等しいとき。

下界①：Jensenで作る

下界 → Eで接する → Mで上げる → はさむ

\begin{aligned} \ell(\boldsymbol\theta)&=\sum_{i=1}^{n}\log\sum_{q=1}^{k}r_{iq}\,\frac{\phi_{iq}(\boldsymbol\theta)}{r_{iq}}\\ &\ge\sum_{i=1}^{n}\sum_{q=1}^{k}r_{iq}\log\frac{\phi_{iq}(\boldsymbol\theta)}{r_{iq}}=L(\mathbf R,\boldsymbol\theta) \end{aligned}

\phi_{iq}=\pi_qN_{iq}。r_{iq}/r_{iq}=1 を掛け、道具の w_q=r_{iq}、a_q=\phi_{iq}/r_{iq} とした。右辺を下界 L と呼ぶ。\mathbf R は、各行の和が1で成分が正なら何でもよい。

下界②：Eで接する

下界 → Eで接する → Mで上げる → はさむ

卵で \mu_2 だけを動かした。Eステップの \mathbf R ではJensenの等号が成り立ち、下界 L（緑の破線）は今の \mu_2 で \ell（黒）に接し、L(\mathbf R^{(t)},\boldsymbol\theta^{(t)})=\ell(\boldsymbol\theta^{(t)}) となる。

下界③：Mで上げる

下界 → Eで接する → Mで上げる → はさむ

Mステップは、\mathbf R を固定して下界の山頂（重み付きの平均 64.5 g）へ動かす。下界は 19.2 上がり、\ell は 27.9 上がった。

下界④：はさむ

下界 → Eで接する → Mで上げる → はさむ

\begin{aligned} \ell(\boldsymbol\theta^{(t+1)})&\ \ge\ L(\mathbf R^{(t)},\boldsymbol\theta^{(t+1)})\\ &\ \ge\ L(\mathbf R^{(t)},\boldsymbol\theta^{(t)})\ =\ \ell(\boldsymbol\theta^{(t)}) \end{aligned}

上から下界①（どの \boldsymbol\theta でも）、下界③（Mステップ）、下界②（Eステップ）。\ell は毎回上がるか、変わらない。

次の問い：所属を見ずに何がわかるか

  • EMは止まり、卵では2つの山が出た。\ell は毎回上がる
  • 所属は一度も使っていない。それでも、どこまでわかるか

困りごと①②に答えられるかを、人工データで確かめる。

所属を見たS字

所属を見て第6回の式で推定したLDAの事後確率（破線）。重さが増えると、L玉の確率がS字で上がる。

所属を見ずにS字

EMの責任度（緑）は所属を使っていない。それでも、所属を見たLDAに近いS字が出る。

k-meansなら階段

同じ卵をk-meansで分けると、所属は 63.2 gで0から1へ跳ぶ階段（点線）。

貝殻：k-meansの境目

貝殻をk-meansで分ける。境目は垂直二等分線なので、ハマグリの帯の右上の端がホタテの群に入る。

貝殻：群ごとの楕円

EMは群ごとの楕円を推定する。ハマグリの帯に沿った細長い楕円になり、境目が曲がる。

困りごと②に戻る

群ごとに共分散行列 \boldsymbol\Sigma_q を持たせると、群の形と広がりを推定できる。境目は楕円に合わせて曲がる。

境目のそばは半々

丸は最大の責任度が0.9未満の 8 点。どちらとも言えないことを、確率で言える。

困りごと①に戻る

所属は0か1ではなく、責任度という確率で出る。境目のそばの点は「どちらとも言えない」と、数で言える。

次の問い：k-meansとどうつながる

  • どちらも、所属と群のパラメータを交互に更新する
  • 違いは、所属を0/1で持つか、確率で持つか

問い：EMのどこを変えると、k-meansになるか？

σ²を小さくすると

\boldsymbol\Sigma_q=\sigma^2\mathbf I（共通の球）、\pi_q も等しく固定する。\sigma^2 が大きいと、責任度はなだらかなS字。

S字が階段になる

\sigma^2 を小さくすると、S字が急になる。\sigma^2\to0 で、中点での階段になる。

Eは最も近い代表点

r_{iq}=\frac{\exp\bigl(-\lVert\tilde{\boldsymbol x}_i-\boldsymbol\mu_q\rVert_2^2/2\sigma^2\bigr)}{\sum_l\exp\bigl(-\lVert\tilde{\boldsymbol x}_i-\boldsymbol\mu_l\rVert_2^2/2\sigma^2\bigr)} \ \xrightarrow{\ \sigma^2\to0\ }\ \hat g_{iq}

\pi_q と密度の前の係数は打ち消し合う。分母では距離の二乗が最も小さい項が残り、最も近い代表点で1になる。

Mは群の平均

\hat{\mathbf C}=\operatorname{diag}(\mathbf R^\top\mathbf 1_n)^{-1}\mathbf R^\top\mathbf X\ \xrightarrow{\ \mathbf R\to\mathbf G\ }\ (\mathbf G^\top\mathbf G)^{-1}\mathbf G^\top\mathbf X

Mステップは群の平均になる（第7回）。Eが最も近い代表点、Mが群の平均で、k-meansそのもの。

ℓの最大はJの最小

\ell\approx\text{定数}-\frac{J}{2\sigma^2},\qquad J=\lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2

1つの群の項だけが残る。\ell の最大化は J の最小化に一致する。誤差が正規分布なら最尤法が最小二乗法に一致した（第6回）のと同じ関係。

最後の問い：止まった所は最大か

  • \ell は毎回上がり、どこかで止まる
  • k-meansでは、止まる先が初期値しだいだった（第7回）

問い：EMが止まった所は、\ell の最大か？

初期値しだい

貝殻で初期値を 200 通り試し、最大の \ell に着いたのは 180 回。局所解があるので、やり直して最大を採る。

1点に縮むと

群1の平均を1個の卵の重さに置き、その分散を小さくする。山はその1点で、いくらでも高くなる。

ℓはいくらでも大きい

\begin{aligned} &\mu_1=x_1,\ \ \sigma_1^2\to0\\ \Longrightarrow\quad&\log f_1(x_1)=-\tfrac12\log(2\pi\sigma_1^2)\ \to\ \infty \end{aligned}

ほかの行は群2が受け持てば有限。群ごとに分散を持たせると、\ell の最大が無い。

対角に小さな数を足す

  • 多変量では、群が数点や薄い板に潰れて \boldsymbol\Sigma_q が逆行列を持たなくなると、同じことが起きる
  • \boldsymbol\Sigma_q は1つの群で p(p+1)/2 個の値を持つ。p が大きいと、行の数に比べて多くなりやすい
  • 防ぎ方：\boldsymbol\Sigma_q の対角に小さな数を足す（第4回の罰則と同じ発想）

k-meansと並べる

推定法 最小二乗法：\lVert\mathbf X-\mathbf G\mathbf C\rVert_F^2 を最小 最尤法：\ell=\mathbf 1_n^\top\log(\boldsymbol\Phi\mathbf 1_k) を最大
所属 \mathbf G（0/1） \mathbf R（確率）
片方を固定した更新 最も近い代表点、(\mathbf G^\top\mathbf G)^{-1}\mathbf G^\top\mathbf X E：ベイズの定理、M：\operatorname{diag}(\mathbf R^\top\mathbf 1_n)^{-1}\mathbf R^\top\mathbf X と \boldsymbol\Sigma_q
群の形 等しい球（境目は垂直二等分線） 群ごとの楕円（境目は曲がる）
目的関数 毎回下がる、局所解 毎回上がる、局所解、1点に縮むと \infty

位置づけ：空いたマスを埋める

最小二乗法 最尤法

締め

まとめ①：ラベルを隠したLDA

混合正規分布は、第6回のLDAから所属を隠したもの。\ell=\sum_i\log\sum_q\pi_qN(\tilde{\boldsymbol x}_i;\boldsymbol\mu_q,\boldsymbol\Sigma_q) を最尤法で最大にする。

まとめ②：EMで交互に解く

\ell は毎回上がる（Eで下界が接し、Mで下界を上げる）。止まる先は初期値しだいで、やり直して \ell 最大を採る。

まとめ③：k-meansはその極限

\boldsymbol\Sigma_q=\sigma^2\mathbf I、\sigma^2\to0 で、責任度のS字が \mathbf G の階段になる。

次回予告①：ℓはkで上がる

群を増やせば \ell は上がり続ける。第7回の「群を増やせば J は下がる」と同じ。

次回予告②：推定法では選べない

  • \ell の最大化そのものでは、k は選べない
  • 共分散を群ごとにするか共通にするかも、パラメータの数を変える同じ問題

問い：k をどう選ぶ？

発展

発展：群の数を決めない混合

  • 混合正規分布では、群の数 k を先に決めて与えた
  • k を決めずに、必要なだけ群を使う混合モデルがある
  • 群の数を無限まで許す。データが少なければ使う群は少なく、多ければ増える

1行ずつ群に入れる

i 番目の行は、すでにある群 q に確率 \frac{n_q}{i-1+\alpha}、新しい群に確率 \frac{\alpha}{i-1+\alpha} で入る（n_q はそれまでの人数）。

人の多い卓ほど座りやすい様子から、中華料理店過程と呼ぶ。図は \alpha=2、100 行。

群の数はゆっくり増える

群の数の期待値は \sum_{i=1}^{n}\frac{\alpha}{\alpha+i-1}。上限は無いが、n が大きいと \alpha\log n の速さでしか増えない。細線は20回の試行。

貝殻に当てる

群の数の上限を10にして、貝殻の人工データに当てはめた。混合比率が0.01を超えるのは 3 群だけ。k を与えずに群の数が出る。

無限混合モデルの図

混合正規分布の図。箱 k=1,\dots,K は群ごと、箱 i=1,\dots,n は行ごと。

K\to\infty で、群の数を決めない無限混合モデル（ディリクレ過程混合）。
