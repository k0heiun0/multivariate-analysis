第6回 分類②：最尤法

データの出方を仮定すると、確率が出る

第I部　理論

前回の残り：向きは出た

  • 0/1の目的変数に最小二乗法を当てると、係数の向きはLDAの判別方向になった
  • 群を分ける向きは正しい
  • だが予測値は0と1の外へはみ出し、確率としては読めなかった

新しいデータ：紙幣の真贋

紙幣の画像から測った1つの量（分散）と、偽札（y=1、赤）か真札（y=0、青）か。縦に少しずらして打った。

0/1に直線を当てる

前回のやり方で直線を当てる。\hat y は -0.37 から 1.39 まで、0と1の外へ伸びる。

割合はS字に曲がる

黒の四角は、分散の区間ごとの偽札の割合。0と1の間でS字に曲がるが、直線は曲がれない。

困りごと①：確率で伝えたい

「この札が偽札である確率は？」と聞かれても、直線の \hat y は 1.39 や -0.37 になる。0と1の間に収まる確率がほしい。

困りごと②：3群以上でも確率を

人工データ：みかんを、皮の色の濃さだけで酸っぱい・ふつう・甘いに分けたい。第5回の最小二乗法では、真ん中の群が一度も選ばれなかった（マスキング）。

困りごと③：何倍なりやすいか

確率が 0.32 から 0.68 に上がる。差（0.36）は場所で変わる。1段濃いことの効き目を、場所によらない1つの数で言いたい。

今回の問い

方向は出るが、確率が出ない。確率を出すには？（困りごと①。②③にも答える）

今回覚える言葉

  • 尤度と最尤法、正規分布の密度と累積分布関数
  • 事後確率（ベイズの定理）、シグモイド関数
  • ロジスティック回帰とニュートン法、交差エントロピー
  • オッズとオッズ比
  • ソフトマックス関数（3群以上）

答えの見通し：出方を仮定する

データの出方（確率分布）を仮定する。

そのデータが出てくる確率を最大にするパラメータを選ぶ。これが最尤法。

3段で確かめる

  1. 最小二乗法は、誤差が正規分布のときの最尤法
  2. LDAを最尤法で当てはめる（\boldsymbol x の出方を仮定）
  3. ロジスティック回帰（y の出方だけを仮定）

進め方：まず一周、次に「なぜ」

  • 前半：例と図で、問いの答えまで一周する
  • 後半：前半で「なぜ？」と思うところに戻り、式で確かめる

後半で戻るのは4つ。最小二乗法が最尤法であること、LDAの最尤推定、事後確率の中身が1次式になること、ロジスティック回帰の勾配と山。

位置づけ：推定法が変わる

第5回 第6回（今回）
推定法 最小二乗法（距離を最小に） 最尤法（確率を最大に）
モデル LDA 線形回帰・LDA・ロジスティック回帰
答え 向き（スコア） 確率

第1回の地図で、推定法の列が初めて最尤法に変わる。

言葉を決める

  • 最尤法では「手元のデータが出てくる確率」を式で書き、それを最大にする
  • 要るのは、0か1の量の出方、連続の量の出方、群を見たあとの確率

道具を先にそろえる。

尤度①：0か1の出方

\Pr(y)=\theta^{y}(1-\theta)^{1-y}\qquad(y\in\{0,1\})

コインの表を y=1、裏を y=0、表の確率を \theta とする。y=1 なら \theta、y=0 なら 1-\theta になる。これをベルヌーイ分布と呼ぶ。

尤度②：θの関数として見る

L(\theta)=\textstyle\prod_{i=1}^{10}\theta^{y_i}(1-\theta)^{1-y_i}=\theta^7(1-\theta)^3

10回投げて表が7回。独立なら出やすさは掛け算。データを固定し、\theta の関数と見たものを尤度と呼ぶ。

尤度③：最大は観測の割合

L(\theta)=\theta^7(1-\theta)^3\quad\text{が最大になるのは}\quad \theta=0.7

最大は \theta=0.7（赤の破線）、表が出た割合そのもの。尤度を最大にするパラメータを選ぶのが最尤法。

対数：山頂の位置は同じ

\begin{aligned} \log L(\theta)&=7\log\theta+3\log(1-\theta)\\ \frac{d\log L}{d\theta}&=\frac7\theta-\frac3{1-\theta}=0\ \Longrightarrow\ \hat\theta=0.7 \end{aligned}

積が和になり、微分しやすい。\log は増える関数なので、山頂の位置は変わらない。

正規分布①：1変数の密度

f(x)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\Bigl(-\frac{(x-\mu)^2}{2\sigma^2}\Bigr)

連続の量の出やすさ。\mu から離れるほど、距離の二乗で出にくくなる。

累積分布①：左側の面積

\Phi(x)=\Pr(X\le x)=\int_{-\infty}^{x}f(t)\,dt

標準正規分布で、x より左の面積が \Phi(x)。

累積分布②：S字になる

x を右へ動かすと、面積は0から1へS字で増える。どんな x でも、値は0と1の間に収まる。

たとえ：人ごとの境目

境目が人ごとに正規分布で散らばると、「はい」と答える割合は累積分布の曲線になる。確率がS字に曲がる理由の1つ。

シグモイド①：同じ形を閉じた式で

\operatorname{sig}(a)=\frac{1}{1+e^{-a}}\ \approx\ \Phi(a/1.7)

シグモイド関数。累積正規分布とほぼ重なる。違いは式：\Phi は積分のまま、sig は積分なしで書ける。

正規分布②：多変量の密度

\begin{aligned} f(\boldsymbol x)&=\frac{1}{(2\pi)^{p/2}\lvert\boldsymbol\Sigma\rvert^{1/2}}\exp\Bigl(-\frac12D^2\Bigr)\\ D^2&=(\boldsymbol x-\boldsymbol\mu)^\top\boldsymbol\Sigma^{-1}(\boldsymbol x-\boldsymbol\mu) \end{aligned}

距離の二乗 D^2 が、共分散行列 \boldsymbol\Sigma で測った2次形式になる。等高線は楕円。p=1 なら \boldsymbol\Sigma=\sigma^2 で1変数の式に戻る。

事後確率①：割合×出やすさ

群 q の割合 \pi_q と、群の中の密度 f_q(x) を掛ける。2つの群で \pi_qf_q を描く（赤の群は全体の1/3）。

事後確率②：ベイズの定理

\Pr(y=1\mid\boldsymbol x)=\frac{\pi_1f_1(\boldsymbol x)}{\pi_0f_0(\boldsymbol x)+\pi_1f_1(\boldsymbol x)}

x を見たあとで群1である確率（事後確率）。x=1.5 では、赤の高さ ÷（青＋赤）＝ 0.55。

事後確率③：S字になる

x を動かしながら同じ比を求めると、事後確率は0と1の間でS字に曲がる。

シグモイド②：事後確率の形

\begin{aligned} \frac{\pi_1f_1}{\pi_0f_0+\pi_1f_1}&=\frac{1}{1+e^{-a}}=\operatorname{sig}(a)\\ a&=\log\frac{\pi_1f_1}{\pi_0f_0}=\log\frac{\theta}{1-\theta} \end{aligned}

分母・分子を \pi_1f_1 で割る。どんな a でも0と1の間。a は対数オッズ。

道具がそろった

  • 尤度：データを固定し、パラメータの関数と見た出やすさ。対数をとって最大にする
  • 正規分布の密度：中心から離れるほど、距離の二乗で出にくい
  • 累積分布関数：左側の面積。0と1の間をS字で動く
  • 事後確率：ベイズの定理で出す。シグモイド関数で0と1の間に収まる

まず、知っている最小二乗法に当ててみる。

次の問い：最小二乗法の仮定

  • 第1回から、係数は誤差の二乗和を最小にして決めてきた
  • 最尤法は、データの出方を仮定し、出てくる確率を最大にする

最小二乗法は、確率の言葉では何を仮定していたのか。使いどころ：最小二乗法が正しく働く条件（誤差の出方）を知る。

1変数の回帰をもう一度

人工データ（25点）。第1回と同じく、二乗和を最小にして原点を通る直線を引いた。

モデル：誤差の出方を仮定する

y_i=\beta x_i+\varepsilon_i,\qquad \varepsilon_i\sim N(0,\sigma^2)

y は直線のまわりに、正規分布で散らばって出てくると仮定する（赤の山）。

1点の出やすさ

f(y_i)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\Bigl(-\frac{(y_i-\beta x_i)^2}{2\sigma^2}\Bigr)

正規分布の密度の \mu を \beta x_i に置いただけ。直線から縦に離れるほど出にくい。

尤度：n点の積

L(\beta,\sigma^2)=\prod_{i=1}^{n}\frac{1}{\sqrt{2\pi\sigma^2}}\exp\Bigl(-\frac{(y_i-\beta x_i)^2}{2\sigma^2}\Bigr)

行が独立なら、出やすさは掛け算（コインの尤度と同じ）。これを最大にする \beta を選ぶ。

二乗和の谷底

左の (a) は第1回の目的関数。谷底が最小二乗法の \hat\beta（赤の破線）。

対数尤度の山頂

右の (b) の対数尤度の山頂も、同じ \hat\beta = 0.615 にある。最小二乗法は、誤差が正規分布のときの最尤法。導き方は後半。

分散も推定される

\hat\sigma^2=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat\beta x_i)^2

対数尤度を \sigma^2 の関数として描くと、山頂は残差の二乗和を n で割った値。最小二乗法では出なかった散らばりの大きさも決まる。導き方は後半。

次の問い：0/1のyには？

  • 誤差が正規分布なら、最尤法は最小二乗法と同じ答えを出す
  • だが紙幣の y は0か1しか取らない。y のまわりに正規分布は置けない

0/1の y には、どんな出方を置けばよいか。使いどころ：真か偽か、病気か否かのような0/1の目的変数に、確率の答えを出す。

仮定の置き方は2通り

  1. \boldsymbol x の出方を群ごとに置く → LDA（生成モデル）
  2. y の出方を \boldsymbol x ごとに置く → ロジスティック回帰（識別モデル）

まず1から見る。

人工データ：みかんの色と甘さ

ここでは人工的なデータを使う。みかん 150 個の皮の色の濃さ x と、甘い（y=1、赤）か酸っぱい（y=0、青）か。

LDA：群を選び、群の中で散らばる

\Pr(y_i=q)=\pi_q,\qquad x_i\mid y_i=q\ \sim\ N(\mu_q,\sigma^2)

分散 \sigma^2 は2群で共通。群の中の x の出方まで仮定する：生成モデル。

目的関数：yとxの同時の尤度

\begin{aligned} \ell(\pi_1,\mu_0,\mu_1,\sigma^2)&=\sum_{i=1}^{n}\Bigl[\log\pi_{y_i}+\log f_{y_i}(x_i)\Bigr]\\ f_q(x)&=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\Bigl(-\frac{(x-\mu_q)^2}{2\sigma^2}\Bigr) \end{aligned}

y も x も観測した。両方の出やすさを掛ける（対数で足す）。

最尤推定は数えるだけ

\hat\pi_q=\frac{n_q}{n},\qquad \hat{\boldsymbol\mu}_q=\frac{1}{n_q}\sum_{y_i=q}\boldsymbol x_i,\qquad \hat{\boldsymbol\Sigma}=\mathbf S_{\mathrm W}

群の割合、群の平均、第5回の群の中の共分散行列。数えるだけで決まる（曲線が当てはめた山）。導き方は後半。

次の問い：確率はどう出るか

  • パラメータは、数えるだけで決まった
  • 欲しいのは、x を見たあとの確率 \Pr(y=1\mid x)

ベイズの定理に入れると、どんな形になるか。使いどころ：群ごとのデータの出方がわかっているときに、新しい1つの確率を出す。

事後確率の中身は1次式

\begin{aligned} \Pr(y=1\mid x)&=\operatorname{sig}\bigl(a(x)\bigr)\\ a(x)&=\frac{d}{\sigma^2}\Bigl(x-\frac{\mu_0+\mu_1}{2}\Bigr)+\log\frac{\pi_1}{\pi_0} \end{aligned}

d=\mu_1-\mu_0。ベイズの定理に入れると、中身 a(x) は x の1次式になる。導き方は後半。

a(x)は直線

みかんの人工データの a(x)。直線で、0を横切る所（破線）で確率が1/2になる。

向きはS_W⁻¹d

\begin{aligned} a(\boldsymbol x)&=\boldsymbol w^\top\Bigl(\boldsymbol x-\frac{\boldsymbol\mu_0+\boldsymbol\mu_1}{2}\Bigr)+\log\frac{\pi_1}{\pi_0}\\ \boldsymbol w&=\hat{\boldsymbol\Sigma}^{-1}\boldsymbol d=\mathbf S_{\mathrm W}^{-1}\boldsymbol d \end{aligned}

最尤法でも、第5回の最小二乗法と同じ向き。p=1 なら w=d/\sigma^2。導き方は後半。

確率が出る①：前回の直線

破線は、0/1に当てた直線（前回のやり方）。区間ごとの割合（黒の四角）は曲がるのに、直線は外へ伸びる。

確率が出る②：事後確率

困りごと①の答え。LDAの事後確率（緑）は、どの x でも0と1の間。S字に曲がり、割合を追う。

境界は少ない群の側へ

確率1/2は a=0。境界は中点から \log(\pi_1/\pi_0) の分だけ少ない赤の群の側へ（1.02 → 1.91）。

次の問い：形だけを置いたら？

  • LDAの事後確率は、sig（x の1次式）の形になった
  • その形は、群ごとの正規分布と共通の分散という仮定から出た

x の出方は仮定せず、この形だけを置いたらどうなるか。使いどころ：x の出方がわからない、正規分布に見えないデータ。

ロジスティック回帰：形だけを置く

\Pr(y_i=1\mid x_i)=\theta_i=\operatorname{sig}(\beta_0+\beta x_i)

x の出方は仮定しない：識別モデル。\beta_0,\beta を変えると曲線が動く。どの1本を選ぶか。

ベクトル・行列で

\theta_i=\operatorname{sig}(\boldsymbol x_i^\top\boldsymbol\beta),\qquad \boldsymbol\theta=\operatorname{sig}(\mathbf X\boldsymbol\beta)\quad(\text{成分ごとに}\ \operatorname{sig})

\mathbf X の先頭の列を1にして、切片を \boldsymbol\beta に含める。第1回と同じ掛け算 \mathbf X\boldsymbol\beta を、sigに通す。

1行ずつの出やすさ

曲線は \theta_i。赤（y=1）の行は \theta_i、青（y=0）の行は 1-\theta_i が出やすさ。縦線が短いほど、その行はよく当たっている。

目的関数：ベルヌーイの尤度

\begin{aligned} L(\boldsymbol\beta)&=\prod_{i=1}^{n}\theta_i^{\,y_i}(1-\theta_i)^{1-y_i}\\ \ell(\boldsymbol\beta)&=\sum_{i=1}^{n}\Bigl[y_i\log\theta_i+(1-y_i)\log(1-\theta_i)\Bigr] \end{aligned}

行ごとに表の確率 \theta_i が違うコイン。\ell を最大にする曲線を選ぶ。

交差エントロピー：確率の当たり方

-\frac1n\ell(\boldsymbol\beta)=-\frac1n\sum_{i=1}^{n}\Bigl[y_i\log\theta_i+(1-y_i)\log(1-\theta_i)\Bigr]

符号を反転して n で割ったものを交差エントロピーと呼ぶ。正解の側に付けた確率の -\log の平均で、小さいほどよい。

自信のある誤りに厳しい

正解の側に0.99なら0.01、0.5なら0.69、0.01なら4.61。0.5で切った一致率は、この違いを見ない。

勾配はXᵀ(y−θ)

\frac{\partial\ell}{\partial\boldsymbol\beta}=\mathbf X^\top(\boldsymbol y-\boldsymbol\theta)=\boldsymbol 0 \qquad\text{（第1回：}\ \mathbf X^\top(\boldsymbol y-\mathbf X\boldsymbol\beta)=\boldsymbol 0\text{）}

正規方程式と同じ形（導き方は後半）。ただし \boldsymbol\theta は \boldsymbol\beta をsigの中に含む：閉じた形の解がない。

残差 y−θ

境界の近くの行ほど残差が大きく、勾配を動かす。よく当たる行の残差は0に近い。

山は1つ

\frac{d^2\ell}{d\beta^2}=-\sum_{i}\theta_i(1-\theta_i)\,x_i^2<0

2階微分がいつも負：対数尤度は山が1つ（赤の破線が山頂）。導き方は後半。

ニュートン法：放物線で近づく

\beta\ \leftarrow\ \beta+\frac{\ell'(\beta)}{-\ell''(\beta)}

今の点（橙）で山を放物線で近似し、その頂点（緑）へ跳ぶ。これを繰り返す（ニュートン法）。

次の問い：係数をどう読むか

  • ロジスティック回帰の確率は \operatorname{sig}(\beta_0+\beta x)
  • x が1増えたときの確率の上がり方は、場所で変わる

\beta を、場所によらない「何倍」で読めないか？（困りごと③）使いどころ：「色が1段濃いと、甘い見込みは何倍」と人に伝える。

たとえ：オッズは見込みの比

試合に勝つ確率0.8は、勝つ：負ける ＝ 0.8：0.2 ＝ 4：1。この比 \theta/(1-\theta) をオッズと呼ぶ。0.5ならオッズ1。

対数オッズは1次式

\log\frac{\theta}{1-\theta}=\beta_0+\beta x

確率（a）を対数オッズに直すと、直線（b）。

オッズ比 ＝ e^β

\frac{\text{オッズ}(x+1)}{\text{オッズ}(x)}=e^{\beta}

困りごと③の答え。どこでも、1段濃いとオッズは e^\beta = 4.5 倍（オッズ比）。

変数が多いとき

  • ほかの列を固定したまま、列 j を1増やすと、オッズは e^{\beta_j} 倍
  • 列を標準化したなら、「1標準偏差ぶん」増やしたときの倍率
  • 似た列があると、係数は打ち消し合う（第5回の落とし穴）。オッズ比も同じ

アルゴリズム①：LDAは数えて解く

  1. データ行列 \mathbf X（n\times p）と0/1の \boldsymbol y。群の人数 n_q と割合 \hat\pi_q=n_q/n を数える
  2. 群の平均 \hat{\boldsymbol\mu}_q=\frac{1}{n_q}\mathbf X^\top\boldsymbol e_q（\boldsymbol e_1=\boldsymbol y、\boldsymbol e_0=\mathbf 1-\boldsymbol y）、各行から自分の群の平均を引いた \mathbf R で \mathbf S_{\mathrm W}=\frac1n\mathbf R^\top\mathbf R
  3. 連立方程式 \mathbf S_{\mathrm W}\boldsymbol w=\hat{\boldsymbol\mu}_1-\hat{\boldsymbol\mu}_0 を解き、w_0=-\boldsymbol w^\top\frac{\hat{\boldsymbol\mu}_0+\hat{\boldsymbol\mu}_1}{2}+\log\frac{\hat\pi_1}{\hat\pi_0}
  4. 確率 \boldsymbol\theta=\operatorname{sig}(\mathbf X\boldsymbol w+w_0\mathbf 1)

反復はない。第5回の手順と同じ行列を作り、最後にsigに通すだけ。

アルゴリズム②：ニュートン法

  1. \mathbf X の先頭に1の列を足す（n\times(p+1)）。\boldsymbol\beta=\boldsymbol 0 から始める
  2. \boldsymbol\theta=\operatorname{sig}(\mathbf X\boldsymbol\beta)、\mathbf W=\operatorname{diag}\bigl(\theta_i(1-\theta_i)\bigr)
  3. 連立方程式 (\mathbf X^\top\mathbf W\mathbf X)\,\boldsymbol\Delta=\mathbf X^\top(\boldsymbol y-\boldsymbol\theta) を解き、\boldsymbol\beta\leftarrow\boldsymbol\beta+\boldsymbol\Delta
  4. \boldsymbol\Delta が十分小さくなるまで2〜3を繰り返す。確率は \boldsymbol\theta=\operatorname{sig}(\mathbf X\hat{\boldsymbol\beta})

毎回、重み \mathbf W の付いた正規方程式を解く（反復重み付き最小二乗法）。

次の問い：3群以上なら

  • 2群の確率は \operatorname{sig}（1次式）で出た
  • 群が3つ以上なら、確率をどう出すか

問い：k 群の確率を、同じ考え方で出すには？（困りごと②）使いどころ：品種、等級、手書きの数字のように、群が3つ以上あるとき。

k群のLDA：事後確率

\Pr(y=q\mid x)=\frac{\pi_qf_q(x)}{\sum_{r}\pi_rf_r(x)}=\frac{e^{a_q(x)}}{\sum_{r}e^{a_r(x)}}

a_q(x)=\log\pi_qf_q(x)。分散が共通なら1次式（x^2 の項は比で消える）。3本の直線。

ソフトマックス関数

\operatorname{softmax}(\boldsymbol a)_q=\frac{e^{a_q}}{\sum_{r=1}^{k}e^{a_r}}

k 個の数を、足すと1の確率に直す。

2群ならシグモイド

\frac{e^{a_1}}{e^{a_0}+e^{a_1}}=\frac{1}{1+e^{-(a_1-a_0)}}=\operatorname{sig}(a_1-a_0)

k=2 のソフトマックス関数は、差 a_1-a_0 のシグモイド関数。2群の話は、k 群の特別な場合。

多クラスのロジスティック回帰

\begin{aligned} \theta_{iq}&=\operatorname{softmax}(\mathbf B^\top\boldsymbol x_i)_q,\qquad\boldsymbol\beta_{\text{基準の群}}=\boldsymbol 0\\ \ell(\mathbf B)&=\sum_{i=1}^{n}\sum_{q=1}^{k}y_{iq}\log\theta_{iq},\qquad \frac{\partial\ell}{\partial\mathbf B}=\mathbf X^\top(\mathbf Y-\boldsymbol\Theta) \end{aligned}

\mathbf Y は第5回の指示行列。勾配は2群の \mathbf X^\top(\boldsymbol y-\boldsymbol\theta) と同じ形。ニュートン法で解ける。

困りごと②に戻る

多クラスのロジスティック回帰の確率（上の帯が最大の群）。真ん中の「ふつう」も選ばれる（60 個）。第5回の最小二乗法では 0 個だった。

次の問い：2つの向きは同じか

  • LDAもロジスティック回帰も、確率は x の1次式をsigに通した形
  • LDAは数えて解き、ロジスティック回帰は反復で解く

同じ形の確率なら、同じ向きに着くのか。使いどころ：どちらのモデルを使うかを、データの形から選ぶ。

同じ形、違う式

\begin{aligned} \text{LDA}&:\quad \boldsymbol w=\mathbf S_{\mathrm W}^{-1}(\hat{\boldsymbol\mu}_1-\hat{\boldsymbol\mu}_0)\\ \text{ロジスティック回帰}&:\quad \mathbf X^\top(\boldsymbol y-\boldsymbol\theta)=\boldsymbol 0 \end{aligned}

確率の形は同じsig(1次式)。係数を決める式が違う。

何に合わせるかが違う

  • LDA：すべての行の群の平均と群の中の広がりで、向きが決まる
  • ロジスティック回帰：y_i-\theta_i が大きい、当てにくい行が向きを動かす
  • よく当たっている行（\theta_i が y_i に近い行）は、ほとんど効かない

仮定が合えば同じ向き

黒がLDA、橙の破線がロジスティック回帰の向き。LDAの仮定どおりのデータでは、差は 1°。

たとえ：似顔絵と境界線

LDA（生成）は、群ごとの似顔絵（出方）を描いてから確率を出す。ロジスティック回帰（識別）は、似顔絵を描かず、境界のまわりの確率だけを合わせる。

遠くの点でLDAが回る

当てやすい点を遠くに足すと、LDAは平均と広がりが動いて 31° 回る。ロジスティック回帰はほとんど動かない（0.0°）。

最後の問い：山頂がないとき

  • ロジスティック回帰の対数尤度は、山が1つ
  • だが、山頂があるとは限らない

データが完全に分けられたら、何が起きるか。使いどころ：ほぼ完全に分けられるデータや、列の多いデータ。

長さでS字の急さが変わる

x=0 で完全に分かれる人工データ。境界は同じ x=0 のまま、\beta が大きいほどS字が急になり、階段に近づく。向きが同じでも、係数の長さで確率が変わる。

山頂がない

\beta を大きくするほど、すべての行で \theta_i が y_i に近づき、\ell は0へ上がり続ける。最尤推定は存在せず、係数は際限なく大きくなる。

罰則で止める

\ell(\boldsymbol\beta)-\frac{\lambda}{2}\sum_{j\ge1}\beta_j^2

第4回のRidgeと同じ罰則。山頂ができる（\lambda=1 で \beta = 2.33）。

ここまでで一周

  • 最小二乗法は、誤差が正規分布のときの最尤法
  • LDAを最尤法で当てはめると、第5回と同じ向き \mathbf S_{\mathrm W}^{-1}\boldsymbol d の上に確率が乗る
  • ロジスティック回帰は形だけを置き、ニュートン法で山頂へ。係数はオッズ比で読む
  • 3群以上はソフトマックス関数。完全に分けられるときは罰則で止める

後半：4つの「なぜ」

  1. なぜ、最小二乗法は最尤法なのか
  2. なぜ、LDAの最尤推定は数えるだけで求まるのか
  3. なぜ、LDAの事後確率の中身は1次式になるのか
  4. なぜ、ロジスティック回帰の勾配は \mathbf X^\top(\boldsymbol y-\boldsymbol\theta) で、山は1つなのか

前半で見た答えに戻り、式で確かめる。

なぜ①：最小二乗法は最尤法

前半：二乗和の谷底と、対数尤度の山頂が同じ所にあった。なぜか。尤度の対数をとって導く。

道筋：最小二乗法は最尤法

\hat{\boldsymbol\beta}\ \text{は}\ \mathbf X^\top\mathbf X\hat{\boldsymbol\beta}=\mathbf X^\top\boldsymbol y\ \text{の解},\qquad \hat\sigma^2=\frac1n\lVert\boldsymbol y-\mathbf X\hat{\boldsymbol\beta}\rVert_2^2

終着駅はこの2つ。モデルは行列で y_i=\boldsymbol x_i^\top\boldsymbol\beta+\varepsilon_i、\varepsilon_i は独立に N(0,\sigma^2)。

  1. 尤度の対数をとる
  2. 二乗和をノルムで書く
  3. \boldsymbol\beta は二乗和の最小
  4. \sigma^2 で微分する

導出の道具①：積の対数は和

\log\prod_{i=1}^{n}a_i=\sum_{i=1}^{n}\log a_i,\qquad \log e^{u}=u

a_i は正の数。掛け算は足し算になり、\exp の対数は指数の中身になる。

導出の道具②：対数と山頂

\log は増える関数。正の値の関数 L と \log L は、同じ点で最大になる（コインの例）。

導出の道具③：負の数を掛ける

c>0\ \text{のとき}\quad \max_{\boldsymbol\beta}\bigl\{b-c\,g(\boldsymbol\beta)\bigr\}\ \text{の点}=\min_{\boldsymbol\beta}\,g(\boldsymbol\beta)\ \text{の点}

b は \boldsymbol\beta によらない数。負の数を掛けると、谷底が山頂に入れかわる。

導出の道具④：対数と逆数の微分

\frac{d\log s}{ds}=\frac1s,\qquad \frac{d}{ds}\,\frac1s=-\frac1{s^2}\qquad(s>0)

\sigma^2 を1つの数 s と見て微分するときに使う。

尤度の対数をとる

対数をとる → ノルムで書く → 二乗和の最小 → \sigma^2 で微分

\log L=\sum_{i=1}^{n}\Bigl[-\frac12\log(2\pi\sigma^2)-\frac{(y_i-\boldsymbol x_i^\top\boldsymbol\beta)^2}{2\sigma^2}\Bigr]

道具①で、積を和にし、\exp の対数を指数の中身にした。\sqrt{2\pi\sigma^2} の逆数の対数は -\frac12\log(2\pi\sigma^2)。

二乗和をノルムで書く

対数をとる → ノルムで書く → 二乗和の最小 → \sigma^2 で微分

\log L=-\frac n2\log(2\pi\sigma^2)-\frac{1}{2\sigma^2}\lVert\boldsymbol y-\mathbf X\boldsymbol\beta\rVert_2^2

第1項は n 個の同じ数の和。y_i-\boldsymbol x_i^\top\boldsymbol\beta は \boldsymbol y-\mathbf X\boldsymbol\beta の第 i 成分なので、二乗の和は \ell_2 ノルムの二乗。

βは二乗和の最小

対数をとる → ノルムで書く → 二乗和の最小 → \sigma^2 で微分

\begin{aligned} &\max_{\boldsymbol\beta}\log L\ \text{の点}=\min_{\boldsymbol\beta}\lVert\boldsymbol y-\mathbf X\boldsymbol\beta\rVert_2^2\ \text{の点}\\ &\Longrightarrow\ \mathbf X^\top\mathbf X\hat{\boldsymbol\beta}=\mathbf X^\top\boldsymbol y \end{aligned}

\boldsymbol\beta は第2項だけに入り、二乗和に負の数 -1/(2\sigma^2) が掛かる（道具③）。道具②より L の最大も同じ点。あとは第1回の正規方程式。

σ²で微分する

対数をとる → ノルムで書く → 二乗和の最小 → \sigma^2 で微分

\begin{aligned} \frac{\partial\log L}{\partial s}&=-\frac{n}{2s}+\frac{1}{2s^2}\lVert\boldsymbol y-\mathbf X\hat{\boldsymbol\beta}\rVert_2^2=0\\ \Longrightarrow\quad\hat\sigma^2&=\frac1n\lVert\boldsymbol y-\mathbf X\hat{\boldsymbol\beta}\rVert_2^2 \end{aligned}

s=\sigma^2 とおき、道具④で微分した（\log(2\pi s)=\log2\pi+\log s）。\hat{\boldsymbol\beta} は s によらないので、先に代入できる。s<\hat\sigma^2 で正、s>\hat\sigma^2 で負なので、ここが山頂。

なぜ②：数えるだけで推定

前半：LDAの最尤推定は、群の割合・群の平均・\mathbf S_{\mathrm W} だった。なぜか。対数尤度を分けて、部分ごとに最大にする。

道筋：LDAの最尤推定

\hat\pi_1=\frac{n_1}{n},\qquad \hat{\boldsymbol\mu}_q=\frac{1}{n_q}\sum_{y_i=q}\boldsymbol x_i,\qquad \hat{\boldsymbol\Sigma}=\mathbf S_{\mathrm W}

終着駅はこの3つ。対数尤度を、\pi の部分と \boldsymbol\mu_q,\boldsymbol\Sigma の部分に分ける。

  1. 対数尤度を2つに分ける
  2. 割合はコインと同じ
  3. 群の中の密度の対数
  4. \boldsymbol\mu_q で微分する
  5. 群の平均になる
  6. 群の中の分散

導出の道具①：コインの山頂

\begin{aligned} \frac{d}{d\pi}\Bigl[n_1\log\pi+n_0\log(1-\pi)\Bigr]&=\frac{n_1}{\pi}-\frac{n_0}{1-\pi}=0\\ \Longrightarrow\quad\hat\pi&=\frac{n_1}{n_0+n_1} \end{aligned}

表 n_1 回・裏 n_0 回のコイン。山頂は表が出た割合（前半の表7回・裏3回なら0.7）。

導出の道具②：2次形式の勾配

\frac{\partial}{\partial\boldsymbol\mu}\,(\boldsymbol x-\boldsymbol\mu)^\top\mathbf A(\boldsymbol x-\boldsymbol\mu)=-2\mathbf A(\boldsymbol x-\boldsymbol\mu)

\mathbf A は対称。第3回の \partial\,\boldsymbol w^\top\mathbf A\boldsymbol w/\partial\boldsymbol w=2\mathbf A\boldsymbol w に、中身 \boldsymbol w=\boldsymbol x-\boldsymbol\mu の微分 -1 を掛けた。

導出の道具③：逆行列があれば0

\mathbf A\boldsymbol v=\boldsymbol 0\ \text{で、}\ \mathbf A^{-1}\ \text{がある}\quad\Longrightarrow\quad\boldsymbol v=\mathbf A^{-1}\boldsymbol 0=\boldsymbol 0

左から \mathbf A^{-1} を掛ける。逆行列があれば、\boldsymbol 0 に移るのは \boldsymbol 0 だけ。

対数尤度を2つに分ける

2つに分ける → 割合 → 密度の対数 → \boldsymbol\mu_q で微分 → 群の平均 → 群の中の分散

\ell=\underbrace{\sum_{i=1}^{n}\log\pi_{y_i}}_{\pi\ \text{だけ}}+\underbrace{\sum_{i=1}^{n}\log f_{y_i}(\boldsymbol x_i)}_{\boldsymbol\mu_q,\ \boldsymbol\Sigma\ \text{だけ}}

1行の出やすさは積 \pi_{y_i}f_{y_i}(\boldsymbol x_i)。なぜ①の道具①で、対数は和になる。2つの部分を別々に最大にすればよい。

割合はコインと同じ

2つに分ける → 割合 → 密度の対数 → \boldsymbol\mu_q で微分 → 群の平均 → 群の中の分散

\sum_{i=1}^{n}\log\pi_{y_i}=n_1\log\pi_1+n_0\log(1-\pi_1) \ \Longrightarrow\ \hat\pi_1=\frac{n_1}{n}

y_i=1 の行が n_1 個、y_i=0 の行が n_0 個あり、\pi_0=1-\pi_1。道具①そのもの。

群の中の密度の対数

2つに分ける → 割合 → 密度の対数 → \boldsymbol\mu_q で微分 → 群の平均 → 群の中の分散

\begin{aligned} \log f_q(\boldsymbol x)=&-\frac p2\log2\pi-\frac12\log\lvert\boldsymbol\Sigma\rvert\\ &-\frac12(\boldsymbol x-\boldsymbol\mu_q)^\top\boldsymbol\Sigma^{-1}(\boldsymbol x-\boldsymbol\mu_q) \end{aligned}

多変量正規分布の密度に、なぜ①の道具①を当てた。\boldsymbol\mu_q が入るのは最後の項だけ。

μ_qで微分する

2つに分ける → 割合 → 密度の対数 → \boldsymbol\mu_q で微分 → 群の平均 → 群の中の分散

\frac{\partial\ell}{\partial\boldsymbol\mu_q} =-\frac12\sum_{y_i=q}\bigl(-2\boldsymbol\Sigma^{-1}(\boldsymbol x_i-\boldsymbol\mu_q)\bigr) =\boldsymbol\Sigma^{-1}\sum_{y_i=q}(\boldsymbol x_i-\boldsymbol\mu_q)

\boldsymbol\mu_q を含むのは群 q の行だけ。\boldsymbol\Sigma^{-1} は対称なので、道具②が使える。

群の平均になる

2つに分ける → 割合 → 密度の対数 → \boldsymbol\mu_q で微分 → 群の平均 → 群の中の分散

\sum_{y_i=q}(\boldsymbol x_i-\hat{\boldsymbol\mu}_q)=\boldsymbol 0 \ \Longrightarrow\ \hat{\boldsymbol\mu}_q=\frac{1}{n_q}\sum_{y_i=q}\boldsymbol x_i

勾配を0とおき、道具③で \boldsymbol\Sigma^{-1} を外した。和を分けると \sum\boldsymbol x_i=n_q\hat{\boldsymbol\mu}_q。

群の中の分散

2つに分ける → 割合 → 密度の対数 → \boldsymbol\mu_q で微分 → 群の平均 → 群の中の分散

p=1:\quad -\frac{n}{2s}+\frac{1}{2s^2}\sum_{q}\sum_{y_i=q}(x_i-\hat\mu_q)^2=0 \ \Longrightarrow\ \hat\sigma^2=s_{\mathrm W}^2

s=\sigma^2 で微分した（なぜ①の \sigma^2 と同じ計算）。p 変数では同じ形の \hat{\boldsymbol\Sigma}=\mathbf S_{\mathrm W} になる（行列での微分が要るので、結果だけ）。

なぜ③：中身は1次式

前半：LDAの事後確率の中身 a(\boldsymbol x) は直線で、向きは \mathbf S_{\mathrm W}^{-1}\boldsymbol d だった。なぜか。密度の比の対数を展開する。

道筋：事後確率の中身

a(\boldsymbol x)=\boldsymbol w^\top(\boldsymbol x-\boldsymbol m)+\log\frac{\pi_1}{\pi_0},\qquad \boldsymbol w=\boldsymbol\Sigma^{-1}\boldsymbol d

終着駅はこの1次式（\boldsymbol m=(\boldsymbol\mu_0+\boldsymbol\mu_1)/2 は中点、\boldsymbol d=\boldsymbol\mu_1-\boldsymbol\mu_0）。

  1. 比の対数を差にする
  2. 定数が消える
  3. 2次形式を展開する
  4. 2次の項が消える
  5. 中点で書き直す

導出の道具①：比の対数は差

\log\frac{a}{b}=\log a-\log b,\qquad \log(ab)=\log a+\log b

a,b は正の数。なぜ①の道具①（積の対数は和）を、割り算にも使う。

導出の道具②：2次形式の展開

(\boldsymbol x-\boldsymbol\mu)^\top\mathbf A(\boldsymbol x-\boldsymbol\mu) =\boldsymbol x^\top\mathbf A\boldsymbol x-2\boldsymbol\mu^\top\mathbf A\boldsymbol x+\boldsymbol\mu^\top\mathbf A\boldsymbol\mu

\mathbf A は対称。1つの数なので \boldsymbol x^\top\mathbf A\boldsymbol\mu=(\boldsymbol x^\top\mathbf A\boldsymbol\mu)^\top=\boldsymbol\mu^\top\mathbf A\boldsymbol x となり、交差項が2つそろう。

導出の道具③：2次の項の差

\boldsymbol\mu_1^\top\mathbf A\boldsymbol\mu_1-\boldsymbol\mu_0^\top\mathbf A\boldsymbol\mu_0 =(\boldsymbol\mu_1-\boldsymbol\mu_0)^\top\mathbf A(\boldsymbol\mu_1+\boldsymbol\mu_0)

\mathbf A は対称。右辺を展開すると、交差項 \boldsymbol\mu_1^\top\mathbf A\boldsymbol\mu_0 と -\boldsymbol\mu_0^\top\mathbf A\boldsymbol\mu_1 が打ち消し合う。a^2-b^2=(a-b)(a+b) と同じ形。

比の対数を差にする

差にする → 定数が消える → 展開 → 2次の項が消える → 中点で書き直す

a(\boldsymbol x)=\log\frac{\pi_1f_1(\boldsymbol x)}{\pi_0f_0(\boldsymbol x)} =\log\frac{\pi_1}{\pi_0}+\log f_1(\boldsymbol x)-\log f_0(\boldsymbol x)

道具①で、比の対数を差に、積の対数を和にした。

定数が消える

差にする → 定数が消える → 展開 → 2次の項が消える → 中点で書き直す

a(\boldsymbol x)=\log\frac{\pi_1}{\pi_0}-\frac12\Bigl[(\boldsymbol x-\boldsymbol\mu_1)^\top\boldsymbol\Sigma^{-1}(\boldsymbol x-\boldsymbol\mu_1)-(\boldsymbol x-\boldsymbol\mu_0)^\top\boldsymbol\Sigma^{-1}(\boldsymbol x-\boldsymbol\mu_0)\Bigr]

なぜ②の \log f_q を入れた。\boldsymbol\Sigma が2群で共通なので、-\frac p2\log2\pi-\frac12\log\lvert\boldsymbol\Sigma\rvert は差で消える。

2次形式を展開する

差にする → 定数が消える → 展開 → 2次の項が消える → 中点で書き直す

\begin{aligned} &(\boldsymbol x-\boldsymbol\mu_q)^\top\boldsymbol\Sigma^{-1}(\boldsymbol x-\boldsymbol\mu_q)\\ &=\boldsymbol x^\top\boldsymbol\Sigma^{-1}\boldsymbol x-2\boldsymbol\mu_q^\top\boldsymbol\Sigma^{-1}\boldsymbol x+\boldsymbol\mu_q^\top\boldsymbol\Sigma^{-1}\boldsymbol\mu_q \end{aligned}

\boldsymbol\Sigma^{-1} は対称なので、道具②が使える。q=0,1 のどちらも同じ形。

2次の項が消える

差にする → 定数が消える → 展開 → 2次の項が消える → 中点で書き直す

[\ \cdot\ ]=-2(\boldsymbol\mu_1-\boldsymbol\mu_0)^\top\boldsymbol\Sigma^{-1}\boldsymbol x +\boldsymbol\mu_1^\top\boldsymbol\Sigma^{-1}\boldsymbol\mu_1-\boldsymbol\mu_0^\top\boldsymbol\Sigma^{-1}\boldsymbol\mu_0

[\ \cdot\ ] は前の枚の角括弧。\boldsymbol x^\top\boldsymbol\Sigma^{-1}\boldsymbol x は2群で同じなので、差で消える。\boldsymbol\Sigma が共通だから。

中点で書き直す

差にする → 定数が消える → 展開 → 2次の項が消える → 中点で書き直す

\begin{aligned} [\ \cdot\ ]&=-2\boldsymbol d^\top\boldsymbol\Sigma^{-1}\boldsymbol x+\boldsymbol d^\top\boldsymbol\Sigma^{-1}(\boldsymbol\mu_0+\boldsymbol\mu_1)=-2\boldsymbol d^\top\boldsymbol\Sigma^{-1}(\boldsymbol x-\boldsymbol m)\\ a(\boldsymbol x)&=\log\frac{\pi_1}{\pi_0}+\boldsymbol d^\top\boldsymbol\Sigma^{-1}(\boldsymbol x-\boldsymbol m)=\boldsymbol w^\top(\boldsymbol x-\boldsymbol m)+\log\frac{\pi_1}{\pi_0} \end{aligned}

道具③で2次の項の差を書きかえ、\boldsymbol m でまとめた。-\frac12 を掛けて、\boldsymbol w=\boldsymbol\Sigma^{-1}\boldsymbol d（\boldsymbol\Sigma^{-1} は対称）。最尤推定ではなぜ②より \hat{\boldsymbol\Sigma}=\mathbf S_{\mathrm W}。

なぜ④：勾配と山の形

前半：勾配は \mathbf X^\top(\boldsymbol y-\boldsymbol\theta)、山は1つで、ニュートン法で山頂へ近づいた。なぜか。シグモイド関数の微分から導く。

道筋：ロジスティック回帰の勾配

\frac{\partial\ell}{\partial\boldsymbol\beta}=\mathbf X^\top(\boldsymbol y-\boldsymbol\theta),\qquad \frac{\partial^2\ell}{\partial\boldsymbol\beta\,\partial\boldsymbol\beta^\top}=-\mathbf X^\top\mathbf W\mathbf X

終着駅はこの2つと、ニュートン法の更新。\mathbf W=\operatorname{diag}\bigl(\theta_i(1-\theta_i)\bigr)。

  1. 1行を a_i で微分する
  2. \boldsymbol\beta で微分する
  3. 足して行列で書く
  4. もう一度微分する
  5. 山は1つ
  6. 放物線の頂点へ跳ぶ

導出の道具①：シグモイドの微分

\frac{d\,\operatorname{sig}(a)}{da}=\operatorname{sig}(a)\bigl(1-\operatorname{sig}(a)\bigr)

微分がシグモイド自身で書ける。赤の曲線で、a=0 で最大の1/4、両端では0に近づく。

導出の道具②：対数をとって微分

\frac{d\log\operatorname{sig}(a)}{da}=1-\operatorname{sig}(a),\qquad \frac{d\log\bigl(1-\operatorname{sig}(a)\bigr)}{da}=-\operatorname{sig}(a)

道具①の微分を、\operatorname{sig}(a) と 1-\operatorname{sig}(a) で割った（\log u の微分は u'/u）。

導出の道具③：合成関数の微分

a=\boldsymbol x_i^\top\boldsymbol\beta\ \text{のとき}\quad \frac{\partial\,g(a)}{\partial\boldsymbol\beta}=g'(a)\,\frac{\partial a}{\partial\boldsymbol\beta}=g'(a)\,\boldsymbol x_i

外側の g を微分し、中身の勾配を掛ける（第5回）。\boldsymbol x_i^\top\boldsymbol\beta の勾配は \boldsymbol x_i（第3回）。

導出の道具④：放物線の頂点

\begin{aligned} &q(t)=c+g\,(t-b)+\frac12h\,(t-b)^2\quad(h<0)\\ &\Longrightarrow\ \text{頂点は}\ t=b-\frac{g}{h} \end{aligned}

q'(t)=g+h(t-b)=0 を解いた。h<0 なので上に凸で、そこが山頂。

導出の道具⑤：山が1つの条件

\begin{aligned} &\ell''(\beta)<0\ \text{（すべての}\ \beta\ \text{で）}\\ &\Longrightarrow\ \ell'(\beta)=0\ \text{の点は多くて1つ} \end{aligned}

傾き \ell' が減り続けるので、0を横切るのは多くて1回。横切れば、そこが唯一の山頂。

1行をaで微分する

1行を a_i で → \boldsymbol\beta で → 行列で → もう一度 → 山は1つ → 放物線の頂点

\begin{aligned} &\frac{d}{da_i}\Bigl[y_i\log\theta_i+(1-y_i)\log(1-\theta_i)\Bigr]\\ &=y_i(1-\theta_i)-(1-y_i)\theta_i=y_i-\theta_i \end{aligned}

\theta_i=\operatorname{sig}(a_i)、a_i=\boldsymbol x_i^\top\boldsymbol\beta。道具②の2つの式を当てた。

βで微分する

1行を a_i で → \boldsymbol\beta で → 行列で → もう一度 → 山は1つ → 放物線の頂点

\frac{\partial}{\partial\boldsymbol\beta}\Bigl[y_i\log\theta_i+(1-y_i)\log(1-\theta_i)\Bigr]=(y_i-\theta_i)\,\boldsymbol x_i

道具③：外側の微分 y_i-\theta_i に、中身 a_i の勾配 \boldsymbol x_i を掛けた。

足して行列で書く

1行を a_i で → \boldsymbol\beta で → 行列で → もう一度 → 山は1つ → 放物線の頂点

\frac{\partial\ell}{\partial\boldsymbol\beta}=\sum_{i=1}^{n}(y_i-\theta_i)\,\boldsymbol x_i=\mathbf X^\top(\boldsymbol y-\boldsymbol\theta)

\mathbf X^\top の第 i 列は \boldsymbol x_i。列に重み y_i-\theta_i を付けて足すのが、ベクトルを右から掛けること。

もう一度微分する

1行を a_i で → \boldsymbol\beta で → 行列で → もう一度 → 山は1つ → 放物線の頂点

\frac{\partial\theta_i}{\partial\boldsymbol\beta}=\theta_i(1-\theta_i)\,\boldsymbol x_i \ \Longrightarrow\ \frac{\partial^2\ell}{\partial\boldsymbol\beta\,\partial\boldsymbol\beta^\top}=-\sum_{i=1}^{n}\theta_i(1-\theta_i)\,\boldsymbol x_i\boldsymbol x_i^\top=-\mathbf X^\top\mathbf W\mathbf X

道具①と③で \theta_i を微分した。勾配の中で \boldsymbol\beta を含むのは -\theta_i\boldsymbol x_i だけ。2階の偏微分を並べた行列がヘッセ行列。

山は1つ

1行を a_i で → \boldsymbol\beta で → 行列で → もう一度 → 山は1つ → 放物線の頂点

\boldsymbol v^\top\bigl(-\mathbf X^\top\mathbf W\mathbf X\bigr)\boldsymbol v=-\sum_{i=1}^{n}\theta_i(1-\theta_i)\,(\boldsymbol x_i^\top\boldsymbol v)^2\le0

0<\theta_i<1 なので、どの向き \boldsymbol v に切っても2階微分は0以下。\mathbf X\boldsymbol v\ne\boldsymbol 0 なら負。p=1 なら \ell''<0 で、道具⑤から山は1つ。

放物線の頂点へ跳ぶ

1行を a_i で → \boldsymbol\beta で → 行列で → もう一度 → 山は1つ → 放物線の頂点

\beta\leftarrow\beta-\frac{\ell'(\beta)}{\ell''(\beta)},\qquad \boldsymbol\beta\leftarrow\boldsymbol\beta+(\mathbf X^\top\mathbf W\mathbf X)^{-1}\mathbf X^\top(\boldsymbol y-\boldsymbol\theta)

今の点で \ell を放物線で近似し（g=\ell'、h=\ell''）、道具④の頂点へ。行列では \ell' を勾配、\ell'' をヘッセ行列に置きかえる。
