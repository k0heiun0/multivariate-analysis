第6回 分類②：最尤法

データの出方を仮定すると、確率が出る

第I部　理論

前回の残り：向きは出た

  • 0/1の目的変数に最小二乗法を当てると、係数の向きはLDAの判別方向になった
  • 群を分ける向きは正しい
  • だが予測値は0と1の外へはみ出し、確率としては読めなかった

新しいデータ：紙幣の真贋

紙幣の画像から測った1つの量（分散）と、偽札（y=1、赤）か真札（y=0、青）か。縦に少しずらして打った。

0/1に直線を当てる

前回のやり方で直線を当てる。\hat y は -0.37 から 1.39 まで、0と1の外へ伸びる。

割合はS字に曲がる

黒の四角は、分散の区間ごとの偽札の割合。0と1の間でS字に曲がるが、直線は曲がれない。

注意：訓練・テスト分割

訓練・テスト分割は、確率を出す分類でも欠かせない（第2回）。第I部では、手元の行はすでに分けた訓練の行とみなす。テストの行での当たり方は、第II部で測る。

困りごと①：確率で伝えたい

「この札が偽札である確率は？」と聞かれても、直線の \hat y は 1.39 や -0.37 になる。0と1の間に収まる確率がほしい。

困りごと②：3群以上でも確率を

人工データ：みかんを、皮の色の濃さだけで酸っぱい・ふつう・甘いに分けたい。第5回の最小二乗法では、真ん中の群が一度も選ばれなかった（マスキング）。

困りごと③：何倍なりやすいか

確率が 0.32 から 0.68 に上がる。差（0.36）は場所で変わる。1段濃いことの効き目を、場所によらない1つの数で言いたい。

今回の問い

方向は出るが、確率が出ない。確率を出すには？（困りごと①。②③にも答える）

今回覚える言葉

  • 尤度と最尤法、累積分布関数とシグモイド関数
  • ロジスティック回帰とニュートン法、交差エントロピー
  • オッズとオッズ比
  • ソフトマックス関数（3群以上）
  • 条件付き確率と事後確率（ベイズの定理）

答えの見通し：出方を仮定する

データの出方（確率分布）を仮定する。

そのデータが出てくる確率を最大にするパラメータを選ぶ。これが最尤法。

3段で確かめる

  1. ロジスティック回帰（y の出方だけを仮定）
  2. 最小二乗法は、誤差が正規分布のときの最尤法
  3. LDAに確率を乗せる（\boldsymbol x の出方も仮定）

進め方：まず一周、次に「なぜ」

  • 前半：例と図で、問いの答えまで一周する
  • 後半：前半で「なぜ？」と思うところに戻り、式で確かめる

後半で戻るのは1つ。ロジスティック回帰の勾配と、対数尤度の山の形。

位置づけ：推定法が変わる

第5回 第6回（今回）
推定法 最小二乗法（距離を最小に） 最尤法（確率を最大に）
モデル LDA 線形回帰・LDA・ロジスティック回帰
答え 向き（スコア） 確率

第1回の地図で、推定法の列が初めて最尤法に変わる。

言葉を決める

  • 最尤法では「手元のデータが出てくる確率」を式で書き、それを最大にする
  • 要るのは、0か1の量の出方と、確率を0と1の間のS字にする関数

道具を先にそろえる。

尤度①：0か1の出方

\Pr(y)=\theta^{y}(1-\theta)^{1-y}\qquad(y\in\{0,1\})

コインの表を y=1、裏を y=0、表の確率を \theta とする。y=1 なら \theta、y=0 なら 1-\theta になる。これをベルヌーイ分布と呼ぶ。

尤度②：θの関数として見る

L(\theta)=\textstyle\prod_{i=1}^{10}\theta^{y_i}(1-\theta)^{1-y_i}=\theta^7(1-\theta)^3

10回投げて表が7回。独立なら出やすさは掛け算。データを固定し、\theta の関数と見たものを尤度と呼ぶ。

尤度③：最大は観測の割合

L(\theta)=\theta^7(1-\theta)^3\quad\text{が最大になるのは}\quad \theta=0.7

最大は \theta=0.7（赤の破線）、表が出た割合そのもの。尤度を最大にするパラメータを選ぶのが最尤法。

対数：山頂の位置は同じ

\begin{aligned} \log L(\theta)&=7\log\theta+3\log(1-\theta)\\ \frac{d\log L}{d\theta}&=\frac7\theta-\frac3{1-\theta}=0\ \Longrightarrow\ \hat\theta=0.7 \end{aligned}

積が和になり、微分しやすい。\log は増える関数なので、山頂の位置は変わらない。

尤度は積、対数尤度は和

\log L(\theta)=\log\prod_{i=1}^{n}f(y_i;\theta)=\sum_{i=1}^{n}\log f(y_i;\theta)

  • サンプルが独立なら、尤度は1サンプルの出やすさ f(y_i;\theta) の積
  • 対数をとると、1サンプルずつの和になる
  • 和の微分は、各項の微分の和

以後の最尤法は、この和を最大にする。

正規分布①：1変数の密度

f(x)=\frac{1}{\sqrt{2\pi\textcolor{red}{\sigma}^2}}\exp\Bigl(-\frac{(x-\textcolor{blue}{\mu})^2}{2\textcolor{red}{\sigma}^2}\Bigr)

連続の量の出やすさ。\mu から離れるほど、距離の二乗で出にくくなる。

累積分布①：左側の面積

\Phi(x)=\Pr(X\le x)=\int_{-\infty}^{x}f(t)\,dt

標準正規分布で、x より左の面積が \Phi(x)。

累積分布②：S字になる

x を右へ動かすと、面積は0から1へS字で増える。どんな x でも、値は0と1の間に収まる。

たとえ：人ごとの境目

境目が人ごとに正規分布で散らばると、「はい」と答える割合は累積分布の曲線になる。確率がS字に曲がる理由の1つ。

シグモイド①：同じ形を閉じた式で

\operatorname{sig}(a)=\frac{1}{1+e^{-a}}\ \approx\ \Phi(a/1.7)

シグモイド関数。累積正規分布とほぼ重なる。違いは式：\Phi は積分のまま、sig は積分なしで書ける。

道具がそろった

  • 尤度：データを固定し、パラメータの関数と見た出やすさ。対数をとって最大にする
  • 正規分布の密度：中心から離れるほど、距離の二乗で出にくい
  • 累積分布関数：左側の面積。0と1の間をS字で動く
  • シグモイド関数：同じS字を、積分なしの式で書く

まず、困りごと①に答える。

次の問い：S字を当てる

  • 偽札の割合は、0と1の間でS字に曲がった
  • シグモイド関数は、0と1の間のS字。中身を動かすと、位置と急さが変わる

中身を x の1次式にして、データに合う1本を選べないか。使いどころ：真か偽か、病気か否かのような0/1の目的変数に、確率の答えを出す。

人工データ：みかんの色と甘さ

ここでは人工的なデータを使う。みかん 150 個の皮の色の濃さ x と、甘い（y=1、赤）か酸っぱい（y=0、青）か。

ロジスティック回帰：形だけを置く

\Pr(y_i=1\mid x_i)=\theta_i=\operatorname{sig}(\beta_0+\beta x_i)

x の出方は仮定しない：識別モデル。\beta_0,\beta を変えると曲線が動く。どの1本を選ぶか。その基準が、ロジスティック回帰の目的関数。

ベクトル・行列で

\theta_i=\operatorname{sig}(\boldsymbol x_i^\top\boldsymbol\beta),\qquad \boldsymbol\theta=\operatorname{sig}(\mathbf X\boldsymbol\beta)

\mathbf X の先頭の列を1にして、切片を \boldsymbol\beta に含める。第1回と同じ掛け算 \mathbf X\boldsymbol\beta を、成分ごとにsigに通す。

1行ずつの出やすさ

曲線は \theta_i。赤（y=1）の行は \theta_i、青（y=0）の行は 1-\theta_i が出やすさ。縦線が短いほど、その行はよく当たっている。

ロジスティック回帰の目的関数

\begin{aligned} L(\boldsymbol\beta)&=\prod_{i=1}^{n}\theta_i^{\,y_i}(1-\theta_i)^{1-y_i}\\ \ell(\boldsymbol\beta)&=\sum_{i=1}^{n}\Bigl[y_i\log\theta_i+(1-y_i)\log(1-\theta_i)\Bigr] \end{aligned}

行ごとに表の確率 \theta_i が違うコイン。この対数尤度 \ell が目的関数で、\ell を最大にする曲線を選ぶ。

交差エントロピー：確率の当たり方

-\frac1n\ell(\boldsymbol\beta)=-\frac1n\sum_{i=1}^{n}\Bigl[y_i\log\theta_i+(1-y_i)\log(1-\theta_i)\Bigr]

符号を反転して n で割ったものを交差エントロピーと呼ぶ。正解の側に付けた確率の -\log の平均で、小さいほどよい。対数尤度の最大は、交差エントロピーの最小と同じ問題。

自信のある誤りに厳しい

正解の側に0.99なら0.01、0.5なら0.69、0.01なら4.61。0.5で切った正解率は、この違いを見ない。

勾配はXᵀ(y−θ)

\begin{aligned} \frac{\partial\ell}{\partial\boldsymbol\beta}=\mathbf X^\top(\boldsymbol y-\boldsymbol\theta)&=\boldsymbol 0\\ \text{（第1回）}\quad\mathbf X^\top(\boldsymbol y-\mathbf X\boldsymbol\beta)&=\boldsymbol 0 \end{aligned}

正規方程式と同じ形（導き方は後半）。ただし \boldsymbol\theta は \boldsymbol\beta をsigの中に含む：閉じた形の解がない。

残差 y−θ

境界の近くの行ほど残差が大きく、勾配を動かす。よく当たる行の残差は0に近い。

山は1つ

\frac{d^2\ell}{d\beta^2}=-\sum_{i}\theta_i(1-\theta_i)\,x_i^2<0

2階微分がいつも負：対数尤度は山が1つ（赤の破線が山頂）。導き方は後半。

ニュートン法：放物線で近づく

\beta\ \leftarrow\ \beta+\frac{\ell'(\beta)}{-\ell''(\beta)}

今の点（橙）で山を放物線で近似し、その頂点（緑）へ跳ぶ。これを繰り返す（ニュートン法）。

次の問い：係数をどう読むか

  • ロジスティック回帰の確率は \operatorname{sig}(\beta_0+\beta x)
  • x が1増えたときの確率の上がり方は、場所で変わる

\beta を、場所によらない「何倍」で読めないか？（困りごと③）使いどころ：「色が1段濃いと、甘い見込みは何倍」と人に伝える。

たとえ：オッズは見込みの比

試合に勝つ確率0.8は、勝つ：負ける ＝ 0.8：0.2 ＝ 4：1。この比 \theta/(1-\theta) をオッズと呼ぶ。0.5ならオッズ1。

対数オッズは1次式

\log\frac{\theta}{1-\theta}=\beta_0+\beta x

確率（a）を対数オッズに直すと、直線（b）。

オッズ比 ＝ e^β

\frac{\text{オッズ}(x+1)}{\text{オッズ}(x)}=e^{\beta}

困りごと③の答え。どこでも、1段濃いとオッズは e^\beta = 4.5 倍（オッズ比）。

変数が多いとき

  • ほかの列を固定したまま、列 j を1増やすと、オッズは e^{\beta_j} 倍
  • 列を標準化したなら、「1標準偏差ぶん」増やしたときの倍率
  • 似た列があると、係数は打ち消し合う（第5回の落とし穴）。オッズ比も同じ

計算の手順：ニュートン法

  1. 訓練の行の \mathbf X の先頭に1の列を足す（n\times(p+1)）。\boldsymbol\beta=\boldsymbol 0 から始める
  2. \boldsymbol\theta=\operatorname{sig}(\mathbf X\boldsymbol\beta)、\mathbf W=\operatorname{diag}\bigl(\theta_i(1-\theta_i)\bigr)
  3. 連立方程式 (\mathbf X^\top\mathbf W\mathbf X)\,\boldsymbol\Delta=\mathbf X^\top(\boldsymbol y-\boldsymbol\theta) を解き、\boldsymbol\beta\leftarrow\boldsymbol\beta+\boldsymbol\Delta
  4. \boldsymbol\Delta が十分小さくなるまで2〜3を繰り返す
  5. テストの行の確率 \boldsymbol\theta=\operatorname{sig}(\mathbf X\hat{\boldsymbol\beta}) を出し、当たり方を測る

毎回、重み \mathbf W の付いた正規方程式を解く（反復重み付き最小二乗法）。

次の問い：3群以上なら

  • 2群の確率は \operatorname{sig}（1次式）で出た
  • 群が3つ以上なら、確率をどう出すか

問い：k 群の確率を、同じ考え方で出すには？（困りごと②）使いどころ：品種、等級、手書きの数字のように、群が3つ以上あるとき。

群ごとに1次式

a_q(\boldsymbol x)=\boldsymbol x^\top\boldsymbol\beta_q\qquad(q=1,\dots,k)

群ごとに1次式を1本ずつ作る。大きいほど、その群らしい。この3本を、足すと1の確率に直したい。

ソフトマックス関数

\operatorname{softmax}(\boldsymbol a)_q=\frac{e^{a_q}}{\sum_{r=1}^{k}e^{a_r}}

k 個の数を、足すと1の確率に直す。

2群ならシグモイド

\frac{e^{a_1}}{e^{a_0}+e^{a_1}}=\frac{1}{1+e^{-(a_1-a_0)}}=\operatorname{sig}(a_1-a_0)

k=2 のソフトマックス関数は、差 a_1-a_0 のシグモイド関数。2群の話は、k 群の特別な場合。

多クラスのロジスティック回帰

\begin{aligned} \theta_{iq}&=\operatorname{softmax}(\mathbf B^\top\boldsymbol x_i)_q,\qquad\boldsymbol\beta_{\text{基準の群}}=\boldsymbol 0\\ \ell(\mathbf B)&=\sum_{i=1}^{n}\sum_{q=1}^{k}y_{iq}\log\theta_{iq},\qquad \frac{\partial\ell}{\partial\mathbf B}=\mathbf X^\top(\mathbf Y-\boldsymbol\Theta) \end{aligned}

\mathbf Y は第5回の指示行列。勾配は2群の \mathbf X^\top(\boldsymbol y-\boldsymbol\theta) と同じ形。ニュートン法で解ける。

困りごと②に戻る

多クラスのロジスティック回帰の確率（上の帯が最大の群）。真ん中の「ふつう」も選ばれる（60 個）。第5回の最小二乗法では 0 個だった。

注意①：群の順序は使わない

ソフトマックス関数のモデルは、群の番号を入れ替えても同じモデルになる。品種のように順序のない群に、そのまま使える。

注意②：順序には別のモデル

酸っぱい・ふつう・甘いには順序がある。このモデルは、その順序を捨てて当てはめている。順序を使うなら、累積ロジットモデルのような、順序に合わせたモデルがある。

最後の問い：山頂がないとき

  • ロジスティック回帰の対数尤度は、山が1つ
  • だが、山頂があるとは限らない

データが完全に分けられたら、何が起きるか。使いどころ：ほぼ完全に分けられるデータや、列の多いデータ。

大きさでS字の急さが変わる

x=0 で完全に分かれる人工データ。境界は同じ x=0 のまま、\beta が大きいほどS字が急になり、階段に近づく。向きが同じでも、係数の大きさで確率が変わる。

山頂がない

\beta を大きくするほど、すべての行で \theta_i が y_i に近づき、\ell は0へ上がり続ける。最尤推定は存在せず、係数は際限なく大きくなる。

罰則で止める

\ell(\boldsymbol\beta)-\frac{\lambda}{2}\sum_{j\ge1}\beta_j^2

第4回のRidgeと同じ罰則。山頂ができる（\lambda=1 で \beta = 2.33）。

次の問い：最小二乗法も最尤法か

  • 第1回から、係数は誤差の二乗和を最小にして決めてきた
  • 最尤法は、データの出方を仮定し、出てくる確率を最大にする

最小二乗法は、確率の言葉では何を仮定していたのか。使いどころ：最小二乗法が正しく働く条件（誤差の出方）を知る。

モデル：誤差の出方を仮定する

y_i=\beta x_i+\varepsilon_i,\qquad \varepsilon_i\sim N(0,\sigma^2)

人工データ（25点）。y は直線のまわりに、正規分布で散らばって出てくると仮定する（赤の山）。

谷底と山頂は同じ所

  1. 二乗和の谷底と、(b) 対数尤度の山頂が、同じ \hat\beta = 0.615 にある。

理由：βは第2項だけ

-\log L(\boldsymbol\beta,\sigma^2)=\frac n2\log(2\pi\sigma^2)+\frac{1}{2\sigma^2}\lVert\boldsymbol y-\mathbf X\boldsymbol\beta\rVert_2^2

負の対数尤度。\boldsymbol\beta を含むのは第2項だけで、二乗和に正の数 1/(2\sigma^2) を掛けたもの。だから、最小にする \boldsymbol\beta は二乗和と同じ。

もう一つの道：xの出方を置く

  • ロジスティック回帰は、y の出方だけを置いた（識別モデル）
  • 第5回のLDAは、群ごとの \boldsymbol x の広がりから向きを出した

群ごとに \boldsymbol x の出方を置くと、LDAにも確率が乗るか。使いどころ：群ごとのデータの出方がわかっているときに、確率を出す。

正規分布②：多変量の密度

\begin{aligned} f(\boldsymbol x)&=\frac{1}{(2\pi)^{p/2}\lvert\textcolor{red}{\boldsymbol\Sigma}\rvert^{1/2}}\exp\Bigl(-\frac12D^2\Bigr)\\ D^2&=(\boldsymbol x-\textcolor{blue}{\boldsymbol\mu})^\top\textcolor{red}{\boldsymbol\Sigma}^{-1}(\boldsymbol x-\textcolor{blue}{\boldsymbol\mu}) \end{aligned}

距離の二乗 D^2 が、共分散行列 \boldsymbol\Sigma で測った2次形式になる。等高線は楕円。p=1 なら \boldsymbol\Sigma=\sigma^2 で1変数の式に戻る。

事後確率①：割合×出やすさ

群 q の割合 \pi_q と、群の中の密度 f_q(x) を掛ける。2つの群で \pi_qf_q を描く（赤の群は全体の1/3）。

条件付き確率①：条件の中の割合

\Pr(y=1\mid B)=\frac{\Pr(y=1\text{ かつ }B)}{\Pr(B)}

B は「x が灰色の範囲に入る」。B が起きたものだけを集め、その中で群1が占める割合。これを条件付き確率と呼ぶ。

条件付き確率②：割合×出やすさ×幅

\Pr(y=q\text{ かつ }B)=\Pr(y=q)\Pr(B\mid y=q)\approx\pi_qf_q(\boldsymbol x)\,h

条件付き確率の定義の分母を払う。群 q の中で B に入る確率は、密度 × 範囲の幅 h。灰色の帯の中の、各色の曲線の下の面積にあたる。

条件付き確率③：分母は群の和

\Pr(B)=\sum_{q}\Pr(y=q\text{ かつ }B)\approx\sum_{q}\pi_qf_q(\boldsymbol x)\,h

どの点もどれか1つの群に属する。だから B の確率は、群ごとの確率の和になる。和の q は全部の群を動く。

条件付き確率④：幅が約分で消える

\Pr(y=1\mid B)\approx\frac{\pi_1f_1(\boldsymbol x)\,h}{\sum_{q}\pi_qf_q(\boldsymbol x)\,h}=\frac{\pi_1f_1(\boldsymbol x)}{\sum_{q}\pi_qf_q(\boldsymbol x)}

②と③を①に入れると h が消える。範囲を狭めた極限を \Pr(y=1\mid\boldsymbol x) と書く。

事後確率②：ベイズの定理

\Pr(y=1\mid\boldsymbol x)=\frac{\pi_1f_1(\boldsymbol x)}{\pi_0f_0(\boldsymbol x)+\pi_1f_1(\boldsymbol x)}

④の群が2つ（q=0,1）の形。この式をベイズの定理と呼ぶ。x を見たあとで群1である確率（事後確率）。x=1.5 では、赤の高さ ÷（青＋赤）＝ 0.55。

事後確率③：S字になる

x を動かしながら同じ比を求めると、事後確率は0と1の間でS字に曲がる。

シグモイド②：事後確率の形

\begin{aligned} \frac{\pi_1f_1}{\pi_0f_0+\pi_1f_1}&=\frac{1}{1+e^{-a}}=\operatorname{sig}(a)\\ a&=\log\frac{\pi_1f_1}{\pi_0f_0}=\log\frac{\theta}{1-\theta} \end{aligned}

分母・分子を \pi_1f_1 で割る。どんな a でも0と1の間。a は対数オッズ。

LDA：群を選び、群の中で散らばる

\Pr(y_i=q)=\pi_q,\qquad x_i\mid y_i=q\ \sim\ N(\mu_q,\sigma^2)

分散 \sigma^2 は2群で共通。群の中の x の出方まで仮定する：生成モデル。

最尤推定は数えるだけ

\hat\pi_q=\frac{n_q}{n},\qquad \hat{\boldsymbol\mu}_q=\frac{1}{n_q}\sum_{y_i=q}\boldsymbol x_i,\qquad \hat{\boldsymbol\Sigma}=\mathbf S_{\mathrm W}

最尤法で当てはめると、群の割合、群の平均、第5回の群の中の共分散行列になる。数えるだけで決まる（曲線が当てはめた山）。

事後確率の中身は1次式

\begin{aligned} \Pr(y=1\mid\boldsymbol x)&=\operatorname{sig}\bigl(a(\boldsymbol x)\bigr)\\ a(\boldsymbol x)&=\boldsymbol w^\top\Bigl(\boldsymbol x-\frac{\boldsymbol\mu_0+\boldsymbol\mu_1}{2}\Bigr)+\log\frac{\pi_1}{\pi_0}\\ \boldsymbol w&=\mathbf S_{\mathrm W}^{-1}\boldsymbol d \end{aligned}

\boldsymbol d=\boldsymbol\mu_1-\boldsymbol\mu_0。共分散行列が2群で共通なので、2次の項は比で消える。向きは第5回と同じ \mathbf S_{\mathrm W}^{-1}\boldsymbol d。

確率が出る：事後確率

LDAの事後確率（緑）は、どの x でも0と1の間。S字に曲がり、割合（黒の四角）を追う。破線は0/1に当てた直線（前回のやり方）。

境界は少ない群の側へ

確率1/2は a=0。境界は中点から \log(\pi_1/\pi_0) の分だけ少ない赤の群の側へ（1.02 → 1.91）。

次の問い：2つの向きは同じか

  • LDAもロジスティック回帰も、確率は x の1次式をsigに通した形
  • LDAは数えて解き、ロジスティック回帰は反復で解く

同じ形の確率なら、同じ向きに着くのか。使いどころ：どちらのモデルを使うかを、データの形から選ぶ。

同じ形、違う式

\begin{aligned} \text{LDA}&:\quad \boldsymbol w=\mathbf S_{\mathrm W}^{-1}(\hat{\boldsymbol\mu}_1-\hat{\boldsymbol\mu}_0)\\ \text{ロジスティック回帰}&:\quad \mathbf X^\top(\boldsymbol y-\boldsymbol\theta)=\boldsymbol 0 \end{aligned}

確率の形は同じsig(1次式)。係数を決める式が違う。

何に合わせるかが違う

  • LDA：すべての行の群の平均と群の中の広がりで、向きが決まる
  • ロジスティック回帰：y_i-\theta_i が大きい、当てにくい行が向きを動かす
  • よく当たっている行（\theta_i が y_i に近い行）は、ほとんど効かない

仮定が合えば同じ向き

黒がLDA、橙の破線がロジスティック回帰の向き。LDAの仮定どおりのデータでは、差は 1°。

たとえ：似顔絵と境界線

LDA（生成）は、群ごとの似顔絵（出方）を描いてから確率を出す。ロジスティック回帰（識別）は、似顔絵を描かず、境界のまわりの確率だけを合わせる。

遠くの点でLDAが回る

当てやすい点を遠くに足すと、LDAは平均と広がりが動いて 31° 回る。ロジスティック回帰はほとんど動かない（0.0°）。

ここまでで一周

  • ロジスティック回帰は sig（1次式）の形を置き、ニュートン法で山頂へ。係数はオッズ比で読む
  • 3群以上はソフトマックス関数。完全に分けられるときは罰則で止める
  • 最小二乗法は、誤差が正規分布のときの最尤法
  • LDAを最尤法で当てはめると、第5回と同じ向き \mathbf S_{\mathrm W}^{-1}\boldsymbol d の上に確率が乗る

後半：残った「なぜ」

  • なぜ、ロジスティック回帰の勾配は \mathbf X^\top(\boldsymbol y-\boldsymbol\theta) で、山は1つなのか

前半で見た答えに戻り、式で確かめる。

なぜ：勾配と山の形

前半：勾配は \mathbf X^\top(\boldsymbol y-\boldsymbol\theta)、山は1つで、ニュートン法で山頂へ近づいた。なぜか。シグモイド関数の微分から導く。

道筋：ロジスティック回帰の勾配

\frac{\partial\ell}{\partial\boldsymbol\beta}=\mathbf X^\top(\boldsymbol y-\boldsymbol\theta),\qquad \frac{\partial^2\ell}{\partial\boldsymbol\beta\,\partial\boldsymbol\beta^\top}=-\mathbf X^\top\mathbf W\mathbf X

終着駅はこの2つと、ニュートン法の更新。\mathbf W=\operatorname{diag}\bigl(\theta_i(1-\theta_i)\bigr)。

  1. 目的関数を書き、1行ずつの項に分ける
  2. 1行の項を a_i で微分する
  3. \boldsymbol\beta で微分する
  4. 足して行列で書く
  5. もう一度微分する
  6. 山は1つ
  7. 放物線の頂点へ跳ぶ

導出の道具①：和は項ごとに微分

\frac{\partial}{\partial\boldsymbol\beta}\sum_{i=1}^{n}\ell_i=\sum_{i=1}^{n}\frac{\partial\ell_i}{\partial\boldsymbol\beta}

和の微分は、各項の微分の和。\boldsymbol\beta によらない定数を掛けた項は、定数を掛けたまま微分する。

導出の道具②：シグモイドの微分

\frac{d\,\operatorname{sig}(a)}{da}=\operatorname{sig}(a)\bigl(1-\operatorname{sig}(a)\bigr)

微分がシグモイド自身で書ける。赤の曲線で、a=0 で最大の1/4、両端では0に近づく。

導出の道具③：対数をとって微分

\begin{aligned} \frac{d\log\operatorname{sig}(a)}{da}&=1-\operatorname{sig}(a)\\ \frac{d\log\bigl(1-\operatorname{sig}(a)\bigr)}{da}&=-\operatorname{sig}(a) \end{aligned}

道具②の微分を、\operatorname{sig}(a) と 1-\operatorname{sig}(a) で割った（\log u の微分は u'/u）。

導出の道具④：合成関数の微分

a=\boldsymbol x_i^\top\boldsymbol\beta\ \text{のとき}\quad \frac{\partial\,g(a)}{\partial\boldsymbol\beta}=g'(a)\,\frac{\partial a}{\partial\boldsymbol\beta}=g'(a)\,\boldsymbol x_i

外側の g を微分し、中身の勾配を掛ける（第5回）。\boldsymbol x_i^\top\boldsymbol\beta の勾配は \boldsymbol x_i（第3回）。

導出の道具⑤：放物線の頂点

\begin{aligned} &q(t)=c+g\,(t-b)+\frac12h\,(t-b)^2\quad(h<0)\\ &\Longrightarrow\ \text{頂点は}\ t=b-\frac{g}{h} \end{aligned}

q'(t)=g+h(t-b)=0 を解いた。h<0 なので上に凸で、そこが山頂。

導出の道具⑥：山が1つの条件

\begin{aligned} &\ell''(\beta)<0\ \text{（すべての}\ \beta\ \text{で）}\\ &\Longrightarrow\ \ell'(\beta)=0\ \text{の点は多くて1つ} \end{aligned}

傾き \ell' が減り続けるので、0を横切るのは多くて1回。横切れば、そこが唯一の山頂。

目的関数を書く

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\begin{aligned} \ell(\boldsymbol\beta)&=\sum_{i=1}^{n}\ell_i\\ \ell_i&=y_i\log\theta_i+(1-y_i)\log(1-\theta_i) \end{aligned}

前半の対数尤度。行 i の項を \ell_i と書く。道具①で、\ell の微分は \ell_i の微分の和になる。

βはa_iを通して入る

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\boldsymbol\beta\ \longrightarrow\ a_i=\boldsymbol x_i^\top\boldsymbol\beta\ \longrightarrow\ \theta_i=\operatorname{sig}(a_i)\ \longrightarrow\ \ell_i

\boldsymbol\beta は、a_i を通してだけ \ell_i に入る。まず \ell_i を a_i で微分し、あとで a_i の勾配を掛ける（道具④）。

ℓ_iをa_iで書く

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\ell_i=y_i\log\operatorname{sig}(a_i)+(1-y_i)\log\bigl(1-\operatorname{sig}(a_i)\bigr)

\theta_i に \operatorname{sig}(a_i) を入れた。y_i は観測した0か1で、a_i によらない定数。

第1項を微分する

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\frac{d}{da_i}\,y_i\log\operatorname{sig}(a_i)=y_i\bigl(1-\operatorname{sig}(a_i)\bigr)=y_i(1-\theta_i)

定数 y_i は掛けたまま。道具③の1つ目の式を使った。

第2項を微分する

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\begin{aligned} &\frac{d}{da_i}\,(1-y_i)\log\bigl(1-\operatorname{sig}(a_i)\bigr)\\ &=-(1-y_i)\operatorname{sig}(a_i)=-(1-y_i)\theta_i \end{aligned}

定数 1-y_i は掛けたまま。道具③の2つ目の式を使った。

足して整理する

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\begin{aligned} \frac{d\ell_i}{da_i}&=y_i(1-\theta_i)-(1-y_i)\theta_i\\ &=y_i-y_i\theta_i-\theta_i+y_i\theta_i=y_i-\theta_i \end{aligned}

展開すると y_i\theta_i が打ち消し合う。残るのは、観測 y_i と確率 \theta_i の差（残差）。

βで微分する

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\frac{\partial\ell_i}{\partial\boldsymbol\beta}=\frac{d\ell_i}{da_i}\,\frac{\partial a_i}{\partial\boldsymbol\beta}=(y_i-\theta_i)\,\boldsymbol x_i

道具④：外側の微分 y_i-\theta_i に、中身 a_i=\boldsymbol x_i^\top\boldsymbol\beta の勾配 \boldsymbol x_i を掛けた。

足して行列で書く

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\frac{\partial\ell}{\partial\boldsymbol\beta}=\sum_{i=1}^{n}(y_i-\theta_i)\,\boldsymbol x_i=\mathbf X^\top(\boldsymbol y-\boldsymbol\theta)

道具①で、行ごとの勾配を足した。\mathbf X^\top の第 i 列は \boldsymbol x_i。列に重み y_i-\theta_i を付けて足すのが、ベクトルを右から掛けること。

もう一度：動くのはθ_iだけ

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\frac{\partial\ell}{\partial\boldsymbol\beta}=\sum_{i=1}^{n}y_i\boldsymbol x_i-\sum_{i=1}^{n}\theta_i\boldsymbol x_i

勾配を2つの和に分けた。第1項は観測だけでできていて、\boldsymbol\beta によらない。微分すると零行列。\boldsymbol\beta を含むのは \theta_i だけ。

θ_iを微分する

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\frac{\partial\theta_i}{\partial\boldsymbol\beta^\top}=\frac{d\operatorname{sig}(a_i)}{da_i}\,\frac{\partial a_i}{\partial\boldsymbol\beta^\top}=\theta_i(1-\theta_i)\,\boldsymbol x_i^\top

道具②で sig を微分し、道具④で中身の勾配を掛けた。横ベクトル \boldsymbol\beta^\top で微分したので、結果も横に並ぶ。

ヘッセ行列にまとめる

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\frac{\partial^2\ell}{\partial\boldsymbol\beta\,\partial\boldsymbol\beta^\top}=-\sum_{i=1}^{n}\boldsymbol x_i\,\theta_i(1-\theta_i)\,\boldsymbol x_i^\top=-\mathbf X^\top\mathbf W\mathbf X

第2項の \theta_i を、前の枚の微分に置きかえた。重み \theta_i(1-\theta_i) を対角に並べた \mathbf W で行列にまとめる。2階の偏微分を並べた行列が、ヘッセ行列。

山は1つ

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\boldsymbol v^\top\bigl(-\mathbf X^\top\mathbf W\mathbf X\bigr)\boldsymbol v=-\sum_{i=1}^{n}\theta_i(1-\theta_i)\,(\boldsymbol x_i^\top\boldsymbol v)^2\le0

0<\theta_i<1 なので、どの向き \boldsymbol v に切っても2階微分は0以下。\mathbf X\boldsymbol v\ne\boldsymbol 0 なら負。p=1 なら \ell''<0 で、道具⑥から山は1つ。

放物線の頂点へ跳ぶ

目的関数 → a_i で微分 → \boldsymbol\beta で微分 → 行列で → もう一度 → 山は1つ → 放物線の頂点

\beta\leftarrow\beta-\frac{\ell'(\beta)}{\ell''(\beta)},\qquad \boldsymbol\beta\leftarrow\boldsymbol\beta+(\mathbf X^\top\mathbf W\mathbf X)^{-1}\mathbf X^\top(\boldsymbol y-\boldsymbol\theta)

今の点で \ell を放物線で近似し（g=\ell'、h=\ell''）、道具⑤の頂点へ。行列では \ell' を勾配、\ell'' をヘッセ行列に置きかえる。

  • LDA：すべての札の平均と散らばりから \boldsymbol w=\mathbf S_{\mathrm W}^{-1}\boldsymbol d を決める。大きさもここで決まる

なぜ桁が動くか

  • 紙幣は4列で、ほぼ完全に分けられる（第I部「山頂がないとき」）
  • そのとき、係数の向きは決まるが、大きさ（S字の急さ）は決まらない。罰則が大きさを決める
  • オッズ比 e^{\beta_j} は大きさで決まるので、罰則しだいで何桁も動く

  • 罰則を外して、ニュートン法を回す

  • 訓練の行で、罰則の強さ \lambda を変えながらロジスティック回帰を当てはめる
  • テストの行で、交差エントロピーを測る（罰則で確率がどう変わるかを見るため）

落とし穴②：罰則で確率が変わる

罰則が0.1を超えるあたりから、テストの交差エントロピーが大きくなる。判定は同じでも、確率の当たり方は罰則の強さで変わる。

落とし穴②：既定は中立でない

既定の \lambda=1（赤）は、罰則なしやLDA（破線）より悪い。罰則の強さは、既定に任せず選ぶもの。

締め

まとめ①：形だけを置いて山を登る

ロジスティック回帰はニュートン法で山頂へ。完全に分けられるときは罰則で止める。罰則の強さで確率が変わる。

まとめ②：最小二乗法も最尤法

誤差が独立な正規分布なら、対数尤度の山頂は二乗和の谷底と同じ場所にある。

まとめ③：LDAに確率が乗る

群ごとの正規分布を最尤法で当てはめると、第5回と同じ向き \mathbf S_{\mathrm W}^{-1}\boldsymbol d の上に確率が乗る。

問い：確率が出た。どこで切り、どう測るか？

発展

発展：見えない能力を測る

  • 試験の点数や、リハビリで「できる動作の数」は、能力そのものではない
  • 問題ごとに難しさが違うのに、合計点はどの問題も1点と数える
  • 能力を見えない量として、確率のモデルに置く

この考え方を、項目反応理論と呼ぶ。

モデル：人と問題の2つの添え字

人 i が問題 j に正解（できる）なら y_{ij}=1、そうでなければ0。

\theta_{ij}=\Pr(y_{ij}=1)=\operatorname{sig}\bigl(a_j(z_i-b_j)\bigr)

  • z_i：人 i の能力。観測されない
  • b_j：問題 j の困難度。z_i=b_j で確率 1/2
  • a_j：問題 j の識別力。大きいほどS字が急

ロジスティック回帰と同じ形

\log\frac{\theta_{ij}}{1-\theta_{ij}}=a_jz_i-a_jb_j

  • 問題 j ごとに見れば、能力 z_i を説明変数とするロジスティック回帰
  • 違いは、説明変数 z_i が観測されないこと
  • z_i・a_j・b_j を合わせて、尤度を最大にして推定する
