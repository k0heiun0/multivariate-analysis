第4回 射影行列——当てはめの幾何

当てはめ値は y の影である——1つの行列から R²・自由度・てこ比・LOO が出てくる

場面：「この1点、抜いたら変わる？」

200点すべてで試せば分かります。 ですが今日は、1回の計算で全部わかる道を作ります。

今回の問い

第1回で R^2 を「説明できた割合」と習った。では、その割合は何で決まるのか。

  • 当てはめの良し悪しを支配しているものは何か
  • なぜ訓練データでの R^2 は楽観的になるのか
  • 交差検証は、なぜ n 回も当てはめ直さなければならないのか

これらはすべて、たった1つの行列から答えが出る。

データの四角形：計画行列

切片の列を足すと \mathbf{X} は 200\times4。この4本の列が張る空間が、今回の主役。

予測値 \hat{\mathbf{y}} は必ずこの空間の中に住む。\mathbf{y} は外にいる。

位置づけ：射影をもう一歩

  • 第1回：\lVert\mathbf{y}-\mathbf{X}\boldsymbol\beta\rVert^2 を最小にして正規方程式を導いた
  • 第1回：それが「残差が \mathbf{X} の列空間と直交する」ことだと図で見た
  • 今回：その射影を行列として取り出す。取り出すと何が分かるかを調べる

定義①：当てはめ値は y の線形変換

\hat{\mathbf{y}}=\mathbf{X}\hat{\boldsymbol\beta}=\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\,\mathbf{y}

  • 真ん中のひとかたまりを \mathbf{H}=\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top と名づける
  • すると \hat{\mathbf{y}}=\mathbf{H}\mathbf{y}。\mathbf{y} に行列を1つ掛けただけのもの
  • この \mathbf{H} を ハット行列 と呼ぶ。\mathbf{y} に帽子をかぶせる行列という意味

定義②：H は何をする行列か

\mathbf{H} は \mathbf{y} を列空間へ落とす写像。光を当てて影を作る操作。

大事なのは、\mathbf{H} が \mathbf{X} だけで決まること。\mathbf{y} は使っていない。

定義③：この回で使う道具

\mathbf{u}^\top\mathbf{v}=0 \;\Longrightarrow\; \lVert\mathbf{u}+\mathbf{v}\rVert^2=\lVert\mathbf{u}\rVert^2+\lVert\mathbf{v}\rVert^2

\operatorname{tr}\mathbf{A}=\sum_i a_{ii}, \qquad \operatorname{tr}(\mathbf{A}\mathbf{B})=\operatorname{tr}(\mathbf{B}\mathbf{A})

  • 直交・三平方の定理：第1回の定義④ → 導出①
  • トレースの巡回性：第1回の定義⑦ → 導出②

性質①：対称かつ冪等

\mathbf{H}^\top=\mathbf{H}, \qquad \mathbf{H}^2=\mathbf{H}

  • 冪等は \mathbf{H}^2=\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\underbrace{\mathbf{X}^\top\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}}_{\mathbf{I}}\mathbf{X}^\top=\mathbf{H} で出る
  • 意味は素直で、一度落とした影にもう一度光を当てても動かない

性質②：残差は当てはめ値と直交

残差も行列で書ける。\mathbf{I}-\mathbf{H} が残差を作る写像である。

\mathbf{e}=(\mathbf{I}-\mathbf{H})\mathbf{y}, \qquad \mathbf{H}(\mathbf{I}-\mathbf{H})=\mathbf{H}-\mathbf{H}^2=\mathbf{O}

読み方：残差は \mathbf{I}-\mathbf{H} を掛けたもの。当てはめ値と直角に交わる。

  • 積がゼロ行列。つまり \hat{\mathbf{y}} と \mathbf{e} は直交する
  • 第1回で図として見た「残差は列空間と直交」（定義③）が代数になった

デモ：H を作って確かめる

print(f"H の形: {H.shape}   対称: {np.allclose(H, H.T)}")
print(f"冪等 H@H == H     : {np.allclose(H @ H, H)}")
print(f"残差と当てはめ値の内積: {e @ yhat:.3e}")

冪等 H@H == H     : True

性質は主張ではなく、数字で確かめられる事実である。

図で見る：影としての当てはめ

直角が立っていることが要点。ここから次の部の話がすべて出てくる。

導出①：ピタゴラスの分解

\lVert\mathbf{y}-\bar{y}\mathbf{1}\rVert^2=\lVert\hat{\mathbf{y}}-\bar{y}\mathbf{1}\rVert^2+\lVert\mathbf{y}-\hat{\mathbf{y}}\rVert^2

教科書の「変動の分解」は、直角三角形の話（定義③の三平方の定理）だった。

［再訪］R² の幾何的意味

R^2=\frac{\lVert\hat{\mathbf{y}}-\bar{y}\mathbf{1}\rVert^2}{\lVert\mathbf{y}-\bar{y}\mathbf{1}\rVert^2}

読み方：R^2 は、全体の長さに対する説明できた長さの二乗比。

ybar = yv.mean()
r2_geo = np.sum((yhat - ybar) ** 2) / np.sum((yv - ybar) ** 2)
print(f"幾何: {r2_geo:.6f}  sklearn: {r2_score(yv, yhat):.6f}")
幾何: 0.897211  sklearn: 0.897211

R^2 は角度の余弦の二乗である。

導出②：trace H = p

\begin{aligned} \operatorname{tr}\mathbf{H}&=\operatorname{tr}\bigl(\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\bigr)\\ &=\operatorname{tr}\bigl((\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{X}\bigr)=\operatorname{tr}\mathbf{I}_p=p \end{aligned}

巡回性（定義③）で \mathbf{X} を後ろへ回すだけ。\mathbf{H} は使った自由度を記憶している。

解釈：使った自由度と残った自由度

n 個から p 本ぶんを使った。残るのは n-p。

\hat\sigma^2=\frac{\mathrm{RSS}}{n-p}

読み方：残差二乗和を、残った自由度 n-p で割る。使った p のぶんだけ割る数が減る。

なぜ n でなく n-p で割るのか。使った自由度を差し引いているからである。

デモ：trace を数える

print(f"trace H = {np.trace(H):.6f}   p = {p}")
print(f"対角成分の和 = {h.sum():.6f}   平均 h_ii = {h.mean():.6f}  (= p/n)")
print(f"残差の自由度 n - p = {n - p}")
trace H = 4.000000   p = 4
対角成分の和 = 4.000000   平均 h_ii = 0.020000  (= p/n)
残差の自由度 n - p = 196

200\times200 の行列なのに、中身の「大きさ」は p=4 しかない。

定義：てこ比 h_ii

\hat{y}_i=\sum_j h_{ij}y_j の j=i の項なので、

h_{ii}=\text{点 } i \text{ が自分自身の予測値をどれだけ引っ張るか}

  • 総和は p、平均は p/n。その2〜3倍を超えるとてこ比が大きい
  • \mathbf{X} だけで決まるので、y の外れとは別の概念

デモ：てこ比の大きい点を見る

平均 0.02 の3倍を超えたのは3点。いずれも newspaper が突出している。 てこ比は全変数で決まるので、1枚の散布図では理由が見えないこともある。

［再訪］第2回の交差検証を思い出す

行を K 個に切り、1つを残して当てはめ、残した行で測る。第2回で学んだ手順である。

K=n まで極端にしたものを LOO（一つ抜き）と呼ぶ。

問い：LOO は n 回必要か

1回ごとに逆行列を解き直す。第2回で「重い」と述べたのはこのため。 本当に200回やらないと出ないのだろうか。

定理：LOO 残差の閉形式

点 i を抜いて予測したときの残差を e_i^{(-i)} と書く。

e_i^{(-i)}=\frac{e_i}{1-h_{ii}}

読み方：その点を抜いたときの残差は、元の残差を 1-h_{ii} で割れば出る。

右辺は1回の当てはめで得た e_i と h_{ii} だけ。n 回ぶんが1回で出る。 これを二乗して足したものを PRESS と呼ぶ。

なぜ成り立つか

  1. 点 i を抜くと、当てはめは「その点に引っ張られていたぶん」だけ動く
  2. その引っ張りの強さこそ h_{ii} である（前の部で定義した）
  3. 抜いた影響を打ち消すと、ちょうど 1/(1-h_{ii}) の倍率が現れる

h_{ii} が小さい点は抜いてもほとんど動かない。h_{ii} が1に近い点は大きく動く。

デモ：閉形式とループの一致

print(f"閉形式 PRESS    : {press_closed:.8f}")
print(f"200回ループ PRESS: {np.sum(np.array(loo_naive) ** 2):.8f}")
閉形式 PRESS    : 589.37996011
200回ループ PRESS: 589.37996011

証明を追わなくても、主張が正しいことは確かめられる。

［再訪］計算コストの意味が変わる

線形回帰に限れば、LOO のほうが安い。

\mathbf{H} は影を作る射影で、LOO は1回で測れる——ただ、この読みには落とし穴があるかもしれない。

帰結①：残差が小さく見える

閉形式の分母をもう一度見る。

e_i^{(-i)}=\frac{e_i}{1-h_{ii}} \quad\Longrightarrow\quad |e_i| = (1-h_{ii})\,|e_i^{(-i)}|

読み方：h_{ii} が大きい点ほど、抜いたときの残差が大きく膨らむ。

h_{ii} が大きいほど訓練残差は本来より小さく出る。 当たっているのではなく、当てはめに参加していただけである。

帰結②：訓練誤差は楽観的

第2回の「訓練誤差は楽観的」を、\mathbf{H} から説明できる。

\sum_i h_{ii}=p ぶんの「自分に近づける力」が働いている。列を増やすほど増える。 R^2 が単調に増えるのも、同じことの言い換えである。

［再訪］K-fold と LOO

手法 分割数 バイアス 分散
K-fold（K=5\sim10） K 個 やや高い 低い
LOO n 個 低い 高い

計算コストは、閉形式があるので判断材料にならない。 選ぶ基準は「速さ」ではなく「バイアスと分散のどちらを抑えたいか」に変わる。

［再訪］標準化残差で読む

r_i=\frac{e_i}{\hat\sigma\sqrt{1-h_{ii}}}

\sqrt{1-h_{ii}} で割って初めて横並びに読める。

落とし穴：H は y を見ていない

\mathbf{H}=\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top に \mathbf{y} は現れない。ここから大事な区別が出る。

  • てこ比が大きい点：説明変数の空間で端にいる。y の値とは無関係
  • 外れ値：y が予測から大きく離れている点
  • 両方を兼ねる点がいちばん危ない。片方だけの点は必ずしも問題ではない

次回への布石：H が壊れるとき

\mathbf{H} を作るには (\mathbf{X}^\top\mathbf{X})^{-1} が要る。ここが不安定だと、

  • てこ比も標準化残差も LOO の閉形式も、すべて信用できなくなる
  • \mathbf{X} の列が互いに似ていると、\mathbf{X}^\top\mathbf{X} は逆行列を取りにくくなる

次回（第5回）は、まさにその状況を扱う。

［再訪］解析フローのどこに効くか

フローの段 \mathbf{H} から言えること
当てはめ 予測は列空間の中だけ
評価 R^2 は辺の比。\hat\sigma^2 は n-p で割る
診断 残差は標準化してから読む
検証 LOO は閉形式で一発

演習科目は各段を実際に回す。こちらは各段が何に支えられているかを見た。

まとめ：H が教えた4つのこと

バラバラに覚えていた4つが、1つの行列から出てきた。

まとめ（3点）

  1. 当てはめ値は \mathbf{y} の射影——その写像が \mathbf{H}=\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top
  2. \mathbf{H} 一つから R^2・自由度・てこ比・LOO が出る——別々の話ではなかった
  3. \mathbf{H} は \mathbf{X} だけで決まる——てこ比と外れ値は別の概念

式を覚えるのではなく、何の射影なのかを見る。これが線形回帰の読み方である。

次回予告

次回（第5回）は、線形回帰がうまくいかない条件を理解する。

  • 多重共線性：列が互いに似ていると \mathbf{X}^\top\mathbf{X} が不安定になる
  • 外挿：学習範囲の外では予測が信頼できない
  • 非線形性の見落とし：標準化残差が教えてくれるサイン

今回の \mathbf{H} が壊れる状況を、正面から扱う回になる。
