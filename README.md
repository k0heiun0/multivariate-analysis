## このリポジトリについて

[Quarto](https://quarto.org/) の Reveal.js 形式で書き出した HTML です。
各回のディレクトリに `index.html` と、図・ライブラリの入った `slide_files/` があります。
読み物ができた回には、同じディレクトリに `reading.pdf` があります。

数式は KaTeX で組んでいます。
